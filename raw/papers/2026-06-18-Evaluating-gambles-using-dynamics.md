# Evaluating gambles using dynamics

## 问题

一个赌局值不值得玩，不能只看它这一把“平均赚多少”。

因为你不是在一张静止表格里生活。你是在一条时间线上生活。今天输掉的钱，会改变你明天能不能继续玩、能玩多大、会不会破产。

这篇论文要解决的是决策理论的老问题：如何评估一个带随机结果的赌局。传统做法是把钱变成效用，再算期望效用。Peters 和 Gell-Mann 说，这一步把问题绕远了。真正缺的不是一个心理效用函数，而是一个动态模型：财富到底是按固定金额变化，还是按比例变化？

一旦动态说清楚，应该优化什么也会跟着变。

## 翻译

把赌局想成一台机器。

你不能只看机器吐出的下一张彩票。你要看它怎么接到你的财富账户上。

如果它每次给你加减固定金额，它像工资条。

如果它每次按你现有财富涨跌比例，它像投资账户。

同一个随机结果，接到不同机器上，长期后果完全不同。

### 先问机器怎么动

论文的第一刀很重要：一个“赌局”只是结果和概率的清单。

```text
结果 A: 赚多少，概率多少
结果 B: 亏多少，概率多少
```

但这个清单本身不够。因为它没说这些结果如何进入时间。

如果重复方式是加法：

```text
W -> W + ΔW
```

那么长期看，正确的测速仪是每单位时间财富变化：

```text
<ΔW> / Δt
```

这就是 Huygens 的标准。它适合小额、固定金额、不会改变本金结构的赌局。

如果重复方式是乘法：

```text
W -> rW
```

那么长期看，正确的测速仪不是财富本身，而是 log 财富的变化：

```text
<Δ log W> / Δt
```

这就是 Laplace 的标准，也是 Kelly criterion 背后的量。

### 为什么期望值会骗人

期望值天然像“很多个我同时玩一把”的平均。

但真实的人没有很多个自己。真实的人只有一个账户，一路滚下去。

论文说，期望值有两种合理用法：

- 你是一个巨大群体的一员，大家能共享结果。
- 你看的那个量是遍历的，群体平均等于时间平均。

个人决策通常不满足第一条。财富过程也常常不满足第二条。

所以直接最大化财富期望值，不一定是理性。它可能只是在替一群可以互相补贴的人做决策，而不是替一个沿时间生活的人做决策。

### “效用函数”可能不是心理，而是坐标变换

传统效用理论说：人会把钱映射成效用，比如 log(W)，因为钱越多，多一块钱的主观价值越小。

Peters 和 Gell-Mann 的转身在这里：

log(W) 未必是人的心理曲线。它也可能只是乘法财富过程的正确坐标。

在乘法世界里：

```text
W -> rW
```

取 log 后：

```text
log(W) -> log(W) + log(r)
```

乘法变成了加法。于是每一轮的增长可以相加，长期平均也有意义。

这一步把“风险厌恶”从心理故事改写成物理故事：你不是怕风险，你是在用对坐标。

### 和凯利公式的关系

凯利公式就是这篇论文在乘法动态里的操作版。

如果下注比例是 f，赢时财富乘上 `1 + bf`，输时乘上 `1 - f`，凯利要最大化：

```text
g(f) = p log(1 + bf) + q log(1 - f)
```

这正是论文说的“时间平均指数增长率”。

所以凯利不是一个孤立的下注技巧。它是一个更大原则的特例：

```text
先指定财富动态
再找这个动态下的遍历增长率
最后最大化这个增长率
```

### 他们为什么要重讲历史

论文花了不少篇幅重讲 Huygens、Bernoulli、Laplace、Menger。

这不是考古癖，而是为了拆掉一个错误路障。

Huygens 用线性期望，适合加性动态。

Bernoulli 引入 log utility，但表达混乱，把心理解释和计算混在一起。

Laplace 实际上写出了期望 log 财富变化，也就是乘法动态下的增长率。

Menger 后来批评无界效用函数，认为 log 这类函数不允许。Peters 和 Gell-Mann 说，这个批评错了，因为它忽略了乘法动态里的破产边界。log 在接近 0 时负无穷，不是数学坏味道，而是在表达破产不可恢复。

也就是说，log 的关键不是“效用无界”，而是“财富归零后出不来”。

## 核心概念

### 动态

一句话：动态就是赌局结果如何沿时间作用到你的财富上。

类比：同一桶水，倒进水杯和倒进水库不是一回事。结果清单只是“水有多少”，动态决定“它进入什么系统”。

为什么重要：没有动态，赌局评估是欠定义的。只给概率和结果，不足以判断个人长期该不该玩。

### 遍历可观测量

一句话：它是那个可以用期望值代表长期时间平均的量。

类比：不要问车身颜色的平均值，要问速度表。不同机器有不同的速度表。加法财富看 `ΔW`，乘法财富看 `Δ log W`。

为什么重要：论文不是反对所有期望值，而是反对对错误对象求期望。找对可观测量，期望值仍然有用。

### 吸收边界

一句话：破产是一个进去后出不来的状态。

类比：游戏里生命值归零，不是分数少一点，而是游戏结束。后面再高的奖励，对已经出局的人都没意义。

为什么重要：这解释了 log 的负无穷。它不是形式缺陷，而是在严肃表达“不能破产”。

## 洞见

风险决策的第一步不是估计收益，而是问：这个结果会以什么动态改变我未来继续参与游戏的能力？

## 博导审稿

选题眼光很强。它抓住了决策理论的底层接口：随机变量本身不够，必须接上时间动态。这个问题一旦讲清楚，效用、风险厌恶、凯利公式、圣彼得堡悖论都能重新排队。

方法成熟度也不错。论文没有发明复杂模型，而是把加法动态、乘法动态和相应的遍历可观测量分清。它的优势是概念干净，缺点是现实世界常常混合动态：工资、投资、负债、消费、保险和制度救助会同时存在。真实决策不一定能简单归到纯加法或纯乘法。

实验诚意不是这篇的重点。它主要是理论与历史澄清，不靠新数据说服人。作为理论论文可以接受，但如果要指导具体投资或组织决策，还需要把动态、约束和破产条件建得更贴近场景。

写作功力强，但有明显战斗姿态。它对传统效用理论和 Menger 的批评很尖锐。尖锐有价值，因为它逼读者重新看“效用函数到底在干什么”。但也要保留一点谨慎：经济学不是完全不知道动态，只是 Peters 这条线要求把时间平均放到更基础的位置。

判决：weak accept。理由是概念贡献扎实，能重排一串老问题；但外推到全部经济学时还需要更细的场景建模。

## 启发

### 迁移

你可以把“先问动态”作为决策前置问题。

看投资，不先问年化收益，而先问它是加法、乘法，还是带破产边界的乘法。

看 AI 项目，不先问单次 demo 多惊艳，而先问每次使用后组织能力是复利增长，还是一次性消耗人力。

看职业选择，不先问这一步收益，而先问它会不会改变你下一步的选择空间。

### 混搭

这篇可以和休谟、波普尔、凯利公式合成一个判断框架：

- 休谟提醒：过去样本不能证明未来。
- 波普尔提醒：要主动找证伪边界。
- 凯利提醒：仓位要最大化长期复合增长。
- Peters/Gell-Mann 提醒：先指定财富动态，否则连该优化什么都没说清。

用在 AI 框架里，就是：不要只看历史成功率，也不要只看一次收益；要看系统在时间中如何学习、复利、失败和恢复。

### 反转

以后看到“这个策略期望收益为正”“这个 AI 工具平均节省 30% 时间”“这个项目 ROI 很高”，先别急着信。

先问五个问题：

1. 这是很多人平均，还是一个主体沿时间反复执行？
2. 成功和失败能不能共享？
3. 失败会不会降低下一轮本金、权限、信用或组织耐心？
4. 是否存在出局点或不可恢复损失？
5. 我们优化的是静态平均，还是长期增长率？

这篇论文给人的最好提醒是：不要在错误坐标里谈理性。
