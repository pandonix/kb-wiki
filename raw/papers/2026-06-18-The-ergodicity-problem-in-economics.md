# The ergodicity problem in economics

## 问题

一个人赌一次，和一千个人各赌一次，不是一回事。

经济学里很多风险问题，默认把这两件事当成一回事。它先算“平均会赚多少”，再推断“一个人该怎么选”。Peters 说，问题就藏在这里：你不是一千个平行宇宙里的你。你只有一条时间线。

这篇论文要打的不是某个小模型，而是一个老习惯：用期望值替代时间过程。这个习惯在某些系统里没问题，比如平衡态物理里的气体。但财富增长通常不是这种系统。一个人的财富会沿着时间滚动，亏损会改变后面的本金，破产还会直接让游戏结束。

所以 Peters 问了一个简单但狠的问题：我们到底应该优化“很多人同时玩一次的平均结果”，还是“一个人连续活下去的增长速度”？

## 翻译

把这篇论文想成一条路。

路左边是一排平行车道。每条车道里都有一个你。有人赚，有人亏。经济学传统上会看所有车道的平均速度。

路右边只有一条车道。里面只有真实的你。你今天亏了，明天就拿更少的钱继续跑。Peters 关心的是这条车道上的长期速度。

### 先看那个硬币赌局

假设抛硬币：

- 正面：财富增加 50%
- 反面：财富减少 40%

如果只看期望财富：

```text
0.5 * 50% + 0.5 * (-40%) = +5%
```

看起来应该玩。

但如果一个人反复玩，财富不是加减固定金额，而是乘上系数：

```text
正面: x -> 1.5x
反面: x -> 0.6x
两轮一正一反: x -> 1.5 * 0.6x = 0.9x
```

平均一次之后，看起来赚 5%。但典型路径里，一正一反后只剩 90%。多玩几轮，真实的人大概率越玩越穷。

这就是全文的锚点：

```text
很多人玩一次: 看期望值
一个人玩很多次: 看时间增长率
```

### 为什么这会撞上期望效用理论

传统经济学早就知道“只看钱的期望值”会出问题。比如圣彼得堡悖论：有些赌局期望收益巨大，但没人愿意花天价去玩。

于是 Daniel Bernoulli 引入效用函数。钱越多，多一块钱带来的感觉越小。用数学说，就是把财富 x 变成 u(x)，再算期望效用。

Peters 的转身在这里：他不说“人心理上风险厌恶”，而说“你选错了要平均的东西”。

如果财富是固定金额一加一减，那么看 x 的变化就行。

如果财富是按比例涨跌，那么应该看 log(x) 的变化。因为比例增长在 log 空间里才变成可加的东西。

于是原来像“心理偏好”的效用函数，在 Peters 这里变成了“这个财富过程的正确测速仪”。

```text
固定金额过程:
x -> x + a
测速仪: x

比例增长过程:
x -> r * x
测速仪: log(x)
```

### 期望效用和遍历经济学长得像，但意思不同

两边都可能写出 log(x)。

期望效用理论说：这个人有一个凹的效用函数，所以他怕风险。

Peters 说：不是他性格怕风险，而是这个游戏的财富动态要求你看 log(x)。如果你看错了指标，就会把正常的保命行为误读成心理偏差。

这很像开车。

在平路上，你看时速表就够了。

在山路上，你还要看油耗、刹车、坡度。不是司机突然变胆小了，是路变了。

### 那实验怎么验证

论文引用了 Copenhagen 小组的实验。

同一批人被放进两种环境：

- 加法环境：赢亏固定金额。
- 乘法环境：赢亏财富比例。

如果期望效用理论对，人的“风险厌恶”主要是个人心理属性。同一个人换环境，不该系统性大变。

如果 Peters 对，人会根据财富动态换测速仪。加法环境更接近线性效用。乘法环境更接近 log 效用。

结果是：所有测试者在乘法环境里都明显向更强“风险厌恶”的方向移动。论文说这更支持遍历经济学。

这个实验不是铁证。样本、训练时间、任务设计都能追问。但它至少给出一个可检验的方向：看人是不是在适配财富过程，而不是只测“固定人格”。

## 核心概念

### 遍历性

一句话：如果一个人沿时间走出来的平均结果，等于很多人同时走出来的平均结果，这个量才是遍历的。

类比：一个人每天吃一家餐厅，吃一百天后的平均体验；和一百个人同一天各吃一家餐厅后的平均体验。两者相等，才可以用后一种替前一种。

为什么重要：经济决策通常发生在一个人的时间线上。只要财富不是遍历的，用群体平均去指导个人长期选择，就会出错。

### 时间平均增长率

一句话：它问的不是“这一把平均赚多少”，而是“我一路玩下去，财富通常以多快速度长大或缩水”。

类比：看项目不能只看单次成交额，还要看长期现金流能不能滚起来。一个案子毛利高但会拖垮团队，它的“期望收益”好看，时间增长率难看。

为什么重要：它把风险问题从心理解释拉回过程解释。先问钱是怎么动的，再问该用什么指标。

### 效用函数的物理解释

一句话：效用函数未必是人的心理曲线，也可能是财富动态对应的正确坐标。

类比：地图有很多投影。你用墨卡托投影看航线，用等面积投影看面积。投影不是地球的性格，是任务需要。

为什么重要：这会反转很多“人不理性”的判断。人拒绝一个期望收益为正的乘法赌局，可能不是认知偏差，而是在保护长期增长率。

## 洞见

很多“非理性”，其实是研究者把别人的一条时间线，误读成了一组可互相补贴的平行样本。

## 博导审稿

选题眼光很好。它抓的是经济学里非常深的一个默认动作：先求期望，再谈决策。这个动作太老，太顺手，很多人已经不再觉得它是一个假设。

方法成熟度要分开看。作为一篇 Perspective，它的概念重构很漂亮。加法过程对应线性，乘法过程对应 log，这个桥搭得清楚。但它不是一篇把所有经济学场景都统一建模的实证论文。很多真实场景里，人会有消费、保险、借贷、制度保护、重复互动、流动性约束。不能拿一个硬币赌局直接横扫全部经济学。

实验诚意有，但证据不算重。Copenhagen 实验有区分力，因为同一批人进入不同财富动态后，行为确实跟着变。但实验更像概念验证。它支持“动态会改变选择”，还不足以证明“期望效用理论整体错了”。

写作功力很强。Peters 会讲故事，知道从圣彼得堡悖论、效用函数、折现一路推到增长率。但他也有一点宣传味。他把主流经济学说成过度心理化，这个批评有力，但略显一刀切。Nature Physics 后续刊出过经济学家的评论《Economists' views on the ergodicity problem》和 Peters 的回应，说明争议点主要在这里：经济学家并不认为他们完全没处理动态、市场、保险和偏好问题；Peters 认为他们仍没有把时间平均作为基础对象。

判决：weak accept。理由是它作为 Perspective 很有思想增量，但作为“经济学基础错误”的总判决，证据还不够压倒性。

## 启发

### 迁移：用在个人决策

你可以把重大选择先分成两类：

- 一次性、可分散、可保险的问题：期望值有用。
- 连续性、会影响后续本金、失败会改变游戏资格的问题：优先看时间增长率。

投资、职业路径、健康、组织信用，更像第二类。一次暴赚不代表长期好。一旦它增加破产、失信、身体崩掉的概率，就要打折。

### 混搭：和 AI 项目判断结合

AI 项目不要只看单次 demo 的期望收益。要问它会不会提高组织的长期学习速度。

一个项目如果每次交付都留下数据、评测、trace、复盘和可复用组件，它的时间增长率高。

一个项目如果每次靠人肉救火、靠供应商黑箱、靠临时 prompt，它可能单次收益好看，但长期增长率低。

这可以接到“token 资本”的框架里：真正的资本不是一次调用模型得到结果，而是每轮使用后系统更会做事。

### 反转：少骂人不理性

看到别人拒绝一个“平均看起来划算”的选择时，先别急着说他保守。

问三个问题：

- 他能不能重复玩很多次？
- 输一次会不会改变后面的本金或资格？
- 他能不能和别人共享风险？

如果答案是否、会、不能，那拒绝可能是对的。

这篇论文给人的最好提醒是：先找过程，再谈偏好。先问路是什么，再评价司机。
