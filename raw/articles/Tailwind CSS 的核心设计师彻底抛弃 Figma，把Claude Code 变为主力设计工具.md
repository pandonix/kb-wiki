Tailwind CSS 的核心设计师老哥 Steve Schoger，把 Claude Code 当做主力设计工具使用了一个月，体验非常惊艳！

老哥不写代码，就连命令行对他来说还很陌生，目前只会切换目录和启动 Claude。但他用CC做出来了一个三栏定价页、一个完整的财务仪表盘，以及一个从零开始构建的产品营销网站。

老哥发了一个一小时的视频专门复盘了全过程，非常炸裂，Agent时代会无限放大大佬本身的能力，人与人的之间的差距会变得特别巨大。这也再次说明CC不仅是程序员用的东西，还有无限空间。这个视频你可以跟着大佬学习CC，学习设计，学习用CC做设计，一举三得。原视频请自行搜索：Steve Schoger，Designing with Claude Code

废话不多说，我这里也根据老哥的视频讲解复盘一下他构建那个营销网站的完整过程，以及过程中凝练出的一套设计细节处理方法。

从一个 Prompt 开始

他给 Claude Code 的初始指令是：设计一个财务 App 的营销主页，这个 App 的核心功能是把所有收入来源汇聚到一个仪表盘里，重点是收入追踪、支出管理、财务预测和税务准备。结构上要有导航栏、主视觉区、Logo 墙、功能介绍区、数据统计区、用户评价区、CTA 区和页脚。

Claude Code 生成了第一版。Steve 觉得可以接受，但立刻开始调整。

他注意到 AI 默认用了翠绿色而不是 indigo，这让他满意，因为 indigo 是他眼中 AI 生成界面的默认色。但更重要的事马上开始了。

让截图代替假 UI

AI 生成的主视觉区里有一个假造的 App 界面。Steve 的第一个动作，是换成真实的 App 截图。

如果你没有专门制作的视觉素材，截图是让主页产生视觉层次最简单的方式，让页面看起来更有内容、更真实。

截图换进去之后，他发现了两个问题：圆角半径不对，颜色体系也不匹配——截图里用的是 neutral 灰，而页面上用的是 slate 灰。他分别用两条指令修掉了这两个问题。

然后是边框处理。原来的截图加了一个纯色边框，配合投影看起来很「脏」。他的解决方案是：不用实色边框，改用 gray-950 颜色、10% 透明度的外环（outer ring）。效果是边框变得干净，和投影自然融合，不再有那种浑浊感。

这个逻辑被他反复用在了整个页面上，包括导航栏底部分割线、按钮边框等所有需要描边的地方。

字体是细节密度最高的地方

他对字体的处理花了相当长时间。

他用的是 Inter，但他要的不是普通版本，而是可变字体（variable font）版本，并且要从 Rasmus 的字体网站加载，因为这个版本提供了 Display 字形，视觉冲击力更强。

Inter 可变字体的另一个优点是支持中间字重。medium 是 500，semibold 是 600，他在两者之间取了 550——这个重量在 CSS 标准字体中不存在，但 variable font 支持任意数值。他认为这个重量在视觉上比两个标准值都更适合大标题。

同时他收紧了字间距（tracking），理由是：字号超过大约 24 到 30 像素之后，收紧字间距会让标题看起来更有分量。

除了主标题，他还处理了眉标（eyebrow text）——那些出现在章节标题上方的小标签。他的处理方式是：换用等宽字体（mono），全部大写，加宽字间距。他认为这个组合会让页面在视觉上显得更经过设计，而不是默认生成的样子。

按钮对齐问题，靠一个 span 技巧解决

页面里有两种按钮：一个实色主按钮，一个加了投影的次级按钮。

问题出在次级按钮上。为了让它有一个干净的边框，他用了 outer ring 方案（ring 而不是 border）。但 ring 在 Tailwind 里实现时会在元素外部额外占 2 像素，导致两个按钮高度不一致。

解决方案来自 tailwindcss的创始人Adam Wathan：把加了 ring 的按钮用一个 span 标签包裹，span 上加 inline-flex 和 p-px，配合 calc 计算来抵消那 2 像素的偏移。Steve 说他完全不理解这段代码的实现原理，但他拿到这个 Tailwind Play 链接之后，直接让 Claude Code 按照这个结构重写了所有按钮。

标题布局：不要居中，试试分栏

AI 默认会把 Hero 区的标题居中对齐。Steve 换成了一种他在 Tailwind Plus 网站上用过的布局：标题左对齐，副标题和按钮放到右侧，比例大约是 3:2。副标题的顶部与标题顶部对齐。

他让副标题字号缩小到 16px，按钮也改成胶囊形（pill-shaped），高度设定为 38px，用 padding 实现而不是 fixed height。

这一系列改动的目的只有一个：让视觉重心更自然，填满空间的方式比居中更有设计感。

功能区的图片定位工具

功能介绍区里放的是 App 截图，但截图需要裁剪和定位——他想在有限的容器里只展示截图的某个关键区域，而不是整张图。

他的做法是：让 Claude Code 临时构建一个可交互的图片定位工具，直接内嵌在他正在构建的页面里。工具做好之后，他用鼠标拖拽把图片调到想要的位置，工具会显示当前坐标值。他把坐标告诉 Claude Code，Claude Code 把数值写入代码，然后移除这个临时工具。

容器背景：用深色加极低透明度

功能区的截图容器，他没有使用白色背景，而是用 gray-950 加 5% 透明度作为背景色。效果是：背景几乎不可见，但截图四周有了一圈极淡的深色氛围，让图片边缘更有定义感。

这和他处理边框的逻辑一致：不用实色，用深色降透明度，让元素过渡更自然。

用户评价区：生成图片做背景

评价卡片他想做成以人物图片为背景，文字叠加在上面的样式。图片来自 ChatGPT 生成的肖像，他把三张图复制到 prompt 里，让 Claude Code 把每张图设成对应卡片的背景，文字白色，底部加渐变蒙层（gradient shim）让文字可读，同时去掉星级评分和头像圆框，把引用文字对齐到卡片底部。

Claude Code 在处理这个需求时，还自动学习了整个页面的间距风格，不用额外说明就把卡片的内外边距调整到了和其他区域一致。

全站网格线：一个让页面更有质感的视觉手法

最后一个大改动是给整个页面加装饰性边框，他把这个效果称为「画布网格」（canvas grid）——Stripe、Linear、Tailwind 官网都在用，每个版块有竖向的包含线，版块之间有横向分割线。

他的要求是：竖线贴合页面容器，横线铺满整个视口宽度（而不只是容器宽度）。他让容器和边框之间保留 8px 的间距，以保持视觉上的呼吸感。

一些通用的设计技巧总结

从这个构建过程里，可以提炼出几个他反复使用的处理方式：

实色边框容易显脏，用深色加低透明度的 ring 代替，边框和投影之间的过渡会更干净。

大字号标题收紧字间距，视觉分量更重。

Inter 可变字体的中间字重（比如 550）比标准字重更灵活，值得在合适的地方用。

眉标用等宽字体加全大写，比普通样式更显质感。

没有视觉素材时，截图是最快的视觉解决方案；没有自定义图形时，装饰性网格线是最快的视觉质感提升方式。

容器背景用极低透明度的深色，比纯白更能托住截图。
