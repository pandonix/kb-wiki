# Token 资本

## 核心定义

**Token 资本（Token Capital）** 是微软 CEO [[satya-nadella|萨提亚·纳德拉]]在 2026 年提出的概念：企业自主构建和掌控的 AI 能力——包括私有评估体系、私有强化学习环境、领域知识库、流程数据、组织判断力与反馈数据等，构成一套由企业掌控、可持续进化的 AI 学习系统。^[raw/articles/2026-06-15-微软CEO长文提出新概念token资本-AI时代企业生死的关键.md]

Token 资本与[[token-economics|Token 经济]]不同：Token 经济关注 Token 作为计量单位的定价、市场和产业；Token 资本关注的是**组织如何将 Token 使用转化为可继承、可验证、可复利的知识资产**。

## 双资本框架：人力资本 + Token 资本

纳德拉提出每家企业必须同时构建两种资本：

- **人力资本**：员工拥有的知识、判断力、人际关系、创造力与规律洞察
- **Token 资本**：企业自主构建和掌控的 AI 能力

关键洞见：**Token 资本的增长不会削弱人力资本的价值，反而会让它更加珍贵。** 人的主动性是驱动 Token 资本增长的核心动力——人类设定远大目标、跨领域连接思维、建立人际网络、识别最关键规律。没有人的引领，计算只是在原地打转。^[raw/articles/2026-06-15-微软CEO长文提出新概念token资本-AI时代企业生死的关键.md]

> 你可以把一项任务、甚至一个岗位外包出去，但你永远无法把学习本身外包出去。企业的未来，在于能否在人与 AI 之间将这种学习持续复利积累。—— Satya Nadella

## 学习闭环：Token 资本的构建方式

Token 资本通过以下核心组件构建企业自己的学习闭环：

1. **私有评估体系**：衡量模型是否真正在改善企业真正在意的业务结果（而非仅仅追随外部排行榜）
2. **私有强化学习环境**：让模型在组织真实数据上越练越强
3. **知识库**：让机构记忆随时可查，让每个 Token 的使用更加高效
4. **模型可替换**：企业应能随时替换底层通用模型，而不丢失已沉淀在学习系统中的「老兵经验」——这是 AI 主权与控制权的核心标准
5. **流程数据与反馈闭环**：每个优化后的工作流产生更优质的训练信号，加速积累只属于这家企业的隐性知识

## 核心战略意义

### AI 主权：避免行业价值外包

纳德拉最担忧的未来是每个行业的每家企业都把自身价值拱手让给少数几个「通吃一切」的 AI 模型。如果全部价值集中在极少数模型手中，政治经济生态必然无法容忍。^[raw/articles/2026-06-15-微软CEO长文提出新概念token资本-AI时代企业生死的关键.md]

类比全球化第一阶段：整个工业经济体系被外包浪潮掏空，GDP 数字不难看但背后冲击真实且余震至今。绝不能将同样逻辑带入 AI 时代。

### Token 资本作为复利资产

Token 资本像一台持续攀登的机器——与大多数资产不同，它会**复利增长**。率先构建这一能力的企业将拥有难以复制的先发优势，无论未来出现何种新模型。

## 对 AI 原生组织的补充

Token 资本概念补强了 [[ai-native-organization|AI Native 组织]]的理论框架：组织中心从积累「人力」转向积累「判断力和学习能力」。真正的 AI 原生组织不是消耗 Token，而是让每次 Token 使用产生可继承、可验证、可复利的组织知识资产。^[raw/articles/2026-06-15-微软CEO长文提出新概念token资本-AI时代企业生死的关键.md]
