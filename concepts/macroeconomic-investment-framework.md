# 宏观经济投资框架

## 核心链条

宏观分析用于投资的目标不是预测 GDP/CPI，而是回答：**经济处在哪个宏观状态？政策会怎么反应？市场价格反映到什么程度？我该用什么资产表达？**

```
增长 / 通胀 / 就业 / 信用 / 财政 / 外部部门
→ 央行、财政、监管政策反应
→ 利率、汇率、信用利差、风险偏好、盈利预期
→ 股票、债券、商品、黄金、外汇、房地产、行业风格
```

## 七大核心框架

1. **增长框架**：判断经济是消费驱动、投资驱动、出口驱动，还是政策托底
2. **通胀框架**：区分需求拉动、成本推动、货币/财政推动、输入型通胀
3. **货币政策与利率框架**：政策利率、实际利率、收益率曲线、流动性、金融条件
4. **信用周期与资产负债表框架**：居民/企业/政府/银行体系/金融市场的信用状况
5. **商业周期框架**：复苏→过热→滞胀→衰退四象限，但需结合估值、仓位、政策
6. **国际收支与汇率框架**：经常账户、资本流动、外汇储备、实际有效汇率、美元周期
7. **市场定价框架**：宏观判断≠投资结论，需加入市场共识、预期差、资产表达

## 关键洞察

- 增长强不一定利好股票，增长弱不一定利空风险资产——取决于市场定价了多少
- 真正的投资问题是：方向？共识？预期差？资产表达？止损条件？
- 资产价格交易的是"预期变化"，不是宏观数据本身

## 实战五步法

1. 判断宏观状态（一句话写清）
2. 判断政策反应（央行/财政/信用/监管）
3. 判断市场定价（已涨多少？已定价多少？）
4. 寻找预期差（增长/通胀/政策/盈利/风险偏好）
5. 选择资产表达（不同观点的不同工具）

## 四大常见错误

1. 把宏观判断当交易信号
2. 只看方向，不看定价
3. 只看单一指标
4. 不写反证条件——没有反证的宏观判断容易变成"讲故事"
