# AI 经济补贴危机

## 核心判断

基于 LLM 的 AI 服务，用固定月费订阅来覆盖高度波动的推理成本，在经济上天然失衡。行业过去几年靠补贴和遮蔽真实成本维持增长。^[
AI 的经济账根本算不通.md
]

## GitHub Copilot 的信号

- 微软连续三年让用户烧掉超过订阅费的 token 成本
- 个人用户月付 $10，公司平均每人月亏 $20+，重度用户成本达 $80/月
- 2026 年转向按 token 计费：$19/月 = $19 的 token 额度
- 微软是资本最充足的公司——如果它都补贴不起，其他公司更不行

## 订阅制的根本问题

AI 订阅用户的成本**剧烈波动**：一个用户偶尔搜索，另一个重构整个代码库。服务提供方几乎没有办法控制：

- 设置使用上限 → 产品变差
- 缩小上下文窗口 → 能力降低
- 推向更小模型 → 质量下降
- 改变价格 → 吓退重度用户

## 真实成本数字

- 一次高级请求 token 消耗约值 $11
- Claude Code 企业用户：平均 $13/活跃日 → ~$273/月 → ~$3,276/年
- 90% 用户 < $30/活跃日 → ~$630/月 → ~$7,560/年
- 10 人团队：$75,600-$756,000/年（取决于日消耗）
- 高盛：部分公司 AI token 支出已达人力的 10%，可能升至 100%

## 次贷式 AI 危机

几乎整个科技行业买进了一项以极低折扣出售的技术：

1. 公司用补贴产品拉用户进门
2. 让用户深度依赖
3. 期望涨价时用户不离开
4. 同时赌 token 成本会下降
5. 但 reasoning model 烧更多 token，成本不降反升

## 数据中心经济账

- 每兆瓦容量需 ~$4,400 万（$3,000 万 IT 设备 + $1,400 万设施）
- 114GW 规划中仅 13% "已运营"
- 大多数数据中心靠 1-2 大客户，长期合同价低于现货
- GPU 折旧 + 技术迭代 → 回本需要很多年

## "苍白之马"信号

当 Anthropic 或 OpenAI 把**所有**订阅用户都转向按 token 计费，就标志着补贴模式终结。

## 三类公司命运

1. **大型组织**（Spotify/Uber 级）：CEO 被 AI 洗脑，预算失控 → 但一次差财报就会改变叙事
2. **小型创业公司**：靠补贴的 Teams 订阅 → 六个月后难说服投资者
3. **个人用户**：每月 $200 → 可能不够完成工作
