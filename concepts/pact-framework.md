# PACT 框架

## 核心定义

Anne-Laure Le Cunff 提出的替代传统 SMART 目标的小实验方法论。PACT 是一个迭代性框架，用于在不确定性中进行可执行的探索，而不是非黑即白地追逐目标。名称来源于四个原则的英文首字母：Purposeful、Actionable、Continuous、Trackable。^[谷歌辞职、创业失败、重读神经科学，她说 AI 时代最危险的事是外包你的思考 ｜ 万有引力.md]

## 四原则

### P - Purposeful（有目的）
你要做的任何实验，都必须是你打心底里充满好奇、真正想要探寻答案的事情。绝不能仅仅因为别人都在做就盲目跟风。与 SMART 目标不同，PACT 强调内在动机而非外部指标。

### A - Actionable（切实可行）
挑选一个你可以利用手头现有资源、就在今天立刻启动的实验，没有任何借口。反衬 SMART 的「Specific」和「Measurable」——PACT 的 Actionable 更强调启动门槛无限降低。

### C - Continuous（持续不断）
一个目标是一发子弹定输赢；而实验，你需要反复试。只有通过重复，你才能分辨出眼前发生的是偶然运气，还是某种必然规律。

### T - Trackable（可追踪）
这和 SMART 目标的「Measurable（可衡量）」不同。在 PACT 框架下，唯一需要追踪的就是你做了还是没做——Yes 或 No。在实验进行过程中不要急于下结论，严禁提前分析数据，等到收集完所有数据再复盘最终结果。

## 目标 vs 实验

| 维度 | 目标 (SMART) | 实验 (PACT) |
|------|------------|------------|
| 成功标准 | 非黑即白：达到或失败 | 学到新知即成功 |
| 结果导向 | 执着于特定结果 | 不论结果走向，发现新知 |
| 迭代方式 | 单次博弈 | 持续迭代 |
| 适用场景 | 已知路径、确定性高 | 未知领域、不确定性高 |
| 心理效应 | 失败=否定 | 失败=学习材料 |

## 与 Think/Make 框架的关系

[[think-make-framework]] 是 PACT 在 Agent 时代个人生产率上的具体化：
- Purposeful → 判断什么值得做（Think 升级）
- Actionable → 把模糊目标翻译成 Agent 能执行的任务（Make 升级）
- Continuous → 把交付复盘成更强工作流
- Trackable → 用可观察的 Make 检验 Think

## 实验的三种决策选项

当一个实验结束时，需要同时审视外部信号（量化数据）和内部信号（个人感受）：

1. **坚持**：外部数据好 + 内部感受 OK
2. **调整方向（Pivot）**：微调参数继续试。例如从每天发布改为每三天发布
3. **喊停**：外部指标惨淡 + 内部信号亮红灯 → 感谢实验给我上的一课

关键判断：如果外部数据漂亮但每天都在崩溃，说明系统出了大问题。^[谷歌辞职、创业失败、重读神经科学，她说 AI 时代最危险的事是外包你的思考 ｜ 万有引力.md]
