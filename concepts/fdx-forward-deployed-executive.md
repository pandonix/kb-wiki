# FDX 前线部署高管（Forward Deployed Executive）

## 核心定义

FDX（Forward Deployed Executive，前线部署高管）是继 FDE（[[forward-deployed-engineer-ai]]）之后出现的更高层级角色：**兼具技术能力、管理能力和创业能力，亲自推动企业将 AI 转化为实际结果。** Rick Manelius 提出：FDE 是"外置 CTO"，FDX 是"外置 CEO"。^[raw/articles/2026-08-04-InfoQ-FDE又不够了.md]

## 为什么 FDE 不够

FDE 解决了技术层面问题，但**距离决定预算、组织结构与企业文化的核心管理者太远**：

- 大型企业软件采购周期 18-24 个月，外部环境以周为单位变化
- >90% 的企业 AI 项目未能实现预期回报——根因不在技术，在组织
- 即使管理者拿到理想答案，也未必采用——除非他们**信任**提供答案的人

## FDX 的职责

### 组织层面
- 帮助高管识别问题、设定优先级
- 跨越阻碍行动的心理和情绪门槛（恐惧、不确定、怀疑）
- 理解管理者的语言与需求，同时解决实际技术障碍

### 能力要求
- **技术能力**：能亲自演示（如 10 分钟 Claude Code 完成非技术创始人计划两周的功能）
- **管理能力**：能推动招聘 AI-first 开发人员、重构团队
- **创业能力**：能快速适应变化、容忍不确定性
- **信任建设**：能在决策者和执行者之间建立双向信任

## 实战案例

- **Ben**：非技术创业者，计划花两周/$30时薪开发功能 → Manelius 10 分钟 Claude Code 演示 → 几天内招聘 AI-first 开发人员 → 几周后此前无法按期完成的客户项目可交付
- **Tyler**：Manelius 持续分享 AI 动态 → 一周内给公司部署两个 OpenClaw → 第二周产品交付速度 3-5 倍提升，团队规模减半

## 国内类似岗位

- **飞书"企业 AI 转型顾问"**：产品上线 + 业务痛点识别 + AI 场景设计 + 效果回收，需客户高层沟通能力
- **百度智能云"智慧工业解决方案架构师"**：与 CXO 沟通 + Token 成本测算 + 推动从试验到规模化
- **华为"AI 解决方案架构师"**：客户中高层对话 + 反馈一线需求给产品规划

## AI FDE 的悖论

Palantir 展示了"AI FDE"——智能体构建智能体。但**AI 越能完成部署中的技术工作，企业就越需要 FDX 承担无法被代码替代的组织判断工作。** 自动化抬高了人对组织判断的要求，而非降低了人的必要性。
