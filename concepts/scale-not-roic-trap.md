# 规模非 ROIC 目标函数陷阱

## 核心命题

寡头高价均衡需要一种纪律：**行情好的时候忍住不扩产**，用产能克制来保住定价权。中国企业（和它们背后的政治推手）系统性地做不到——因为资本的目标函数错了。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 机制：便宜资本 + 增长 KPI + 政治锦标赛

### 三个要素的叠加
1. **便宜、政策导向流动的资本**：过去十几年资本充裕、低成本
2. **增长 KPI 作为考核标准**：奖励「建成了多少」而非「赚回了多少 ROIC」
3. **地方官员晋升锦标赛**：零和排名赛中的政绩竞赛

当目标函数是**规模、份额、就业、GDP** 而非资本回报率时，扩产到把利润打没，对每个局中人都是理性的——哪怕对整个行业是灾难。^[raw/agent/中国企业为何陷入内卷竞争.md]

### 战略行业点名 = 保证过剩
政策点名「战略行业」（光伏、电动车、电池、半导体）→ 所有资本一起涌进同一批被祝福的赛道 → **在被钦定的方向上制造保证过剩。**

## 资本市场把利润博弈变成生存排名赛

在快速扩张行业，企业目标从「利润最大化」变成「市场份额最大化」，因为销量和排名影响：
- 下一轮融资
- 银行授信
- 供应商是否提供账期
- 经销商是否继续合作
- 消费者是否相信品牌能长期存在

于是「卖一辆亏一辆」可能比销量下降更理性——销量下降带来的融资风险比当前亏损更危险。

### 委托—代理问题：为复活而赌博
- 企业失败时，管理层和股东的损失有上限
- 成为最后赢家时，股权收益可能非常大
- 部分损失由债权人、供应商和地方政府承担

这产生类似期权的激励：企业越接近困境，越可能采取激进策略（继续扩产或降价），赌一次翻盘——**风险转移/为复活而赌博**。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 公共品博弈：硬件过度投资、生态投资不足

扩建工厂的收益比较容易归企业自己所有（多建产线 → 销量和市场份额很快体现）。但基础软件、通用标准、底层研发和开发者生态有明显外溢效应。

每家企业倾向于：
- 自己多扩一点产能
- 希望别人承担基础生态建设

纳什均衡结果：**产能投资过多，基础生态投资不足**——典型的公共品问题。

英伟达能够获得高利润，一个重要原因是它把生态投资「私有化」了：软件生态与自家硬件深度绑定，研发收益能够被企业持续获取。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 行业公共壁垒 vs 企业私有壁垒

中国制造业拥有强大的产业集群（完整供应链、大量工程师、快速打样、高效物流），构成「中国制造业整体」的壁垒——外国企业很难完全复制。

但问题在于，这些能力往往能被国内同行共享：
- 同一供应商服务多个品牌
- 工程人才自由流动
- 新工艺通过产业链扩散

形成的是**行业对外壁垒很高，但行业内部企业之间壁垒很低**——对国家制造业竞争力有利，却不一定能给某一家企业带来长期垄断利润。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 两种自我强化的循环

### 内卷均衡（恶性）
产品同质化 → 价格战 → 利润下降 → 只能追求短期销量 → 没有资源建设生态 → 产品更加同质化

### 壁垒均衡（良性）
长期研发投入 → 形成平台或差异化 → 客户转换成本提高 → 获得较高利润 → 继续投入研发和生态 → 壁垒进一步增强

**从一个均衡跳到另一个均衡不容易**——平台建设需要在获得回报之前，先承担巨额固定成本，并协调开发者、客户、供应商和人才同时加入。^[raw/agent/中国企业为何陷入内卷竞争.md]
