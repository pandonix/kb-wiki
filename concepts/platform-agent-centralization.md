# 平台 Agent 的中心化张力

## 核心矛盾

AI Agent 时代，平台面临一个根本性选择：**Agent 的调度权（决定调用谁的服务、按什么顺序、推荐谁）应该属于谁？** 这个问题涉及分发权、利益分配、商家博弈和平台治理哲学。

## 三个落点

选择权本质上有三个落点：^[raw/agent/微信AI Agent.md]

| 落点 | 描述 | 问题 |
|------|------|------|
| **平台侧 Agent** | 平台选、平台排序、平台调度 | 最大化中心化，平台成为"推荐人"——变现咽喉 |
| **用户主权 Agent** | 按用户声明的目标函数查询排序 | 注册表和信号由平台控制，"用户主权"可能是化妆品 |
| **对等协商市场** | 用户 Agent ↔ 商家 Agent 实时撮合 | 架构上最干净，但要对抗四股中心化引力 |

## 四股中心化引力

即便设计出去中心化版本，也会被四股力量往中心拽：^[raw/agent/微信AI Agent.md]

1. **收入引力**：守门人/推荐人的位置最赚钱（广告和竞价），纯协议+结算层赚得少得多
2. **信任引力**："保证办成事"需要策展（筛选/过滤/排序），这与去中心化直接对冲——**最硬的矛盾**
3. **成本引力**：多 Agent 实时竞价 = 多轮推理 = 慢且贵；预计算的中心化排序便宜得多
4. **数据引力**：平台看得见所有交易，能训出最好的选择模型；"最好推荐者"因数据优势自然聚到中心

## 对微信的具体含义

微信 Agent 的核心张力：**张小龙坚持的去中心化 vs Agent 调度必然需要的选择权集中**。^[raw/agent/微信AI Agent.md]

微信独特之处：已经握着支付和金融（在结算层赚钱），不需要靠垄断推荐位变现。这给了它走第三条路的可能性——盈利从"排序抽成"换成"结算抽成"。**中心化不是技术逼出来的，是变现模式选出来的。**^[raw/agent/微信AI Agent.md]

### 组织理性 vs 个体理性

- 对平台整体：中立基础设施是长期价值最大、最难被攻击的位置
- 对 BU/PM（受季度考核）：咽喉抽成是局部最优

第三条路需要自上而下的信念来对抗局部优化——**这就是为什么微信 Agent 项目直接向张小龙汇报**。^[raw/agent/微信AI Agent.md]

## Perez 视角

- 去中心化协议层 = 安装期基础设施下注：铺中立轨道，在结算处取值
- 中心化推荐位 = 部署期食利位置：短期肥美，长期易僵化并招致反噬

^[raw/agent/微信AI Agent.md]

## 关键机制设计问题

去中心化方案的全部成败系于：**质量信号是否可审计、不可购买**。这是一个承诺可信度（credible commitment）问题——平台如何向商家和用户证明自己不会在未来某天把排序权变回变现工具。^[raw/agent/微信AI Agent.md]
