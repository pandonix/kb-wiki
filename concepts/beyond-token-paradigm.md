# 超越 Token 范式：连续表征与下一代架构

## 核心命题

当前主流大语言模型的自回归范式（逐 Token 预测）可能只是通往 AGI 的局部最优解。2026 年 5 月，MIT 何恺明团队的 ELF 和字节跳动 Seed 团队的 Cola DLM 几乎同时发表论文，提供了首批工程实验硬证据：语言生成的核心建模过程不必始终发生在离散 Token 空间中，也可以转移到连续 Embedding 或 Latent 空间完成，最后再映射回文本。

## Token 范式的结构性天花板

维特根斯坦的洞见——"我语言的局限即我世界的局限"——精确描述了大语言模型的困境：如果 AI 的"语言"就是离散 Token 序列，它的"世界"永远被困在 Token 能表达的范围内。

人类语言是进化设计的有损压缩协议——大脑内部认知是连续的、并行的、高维的，语言只是跨脑传输的工程妥协。自回归模型在这个压缩产物的输出格式上建模，无法理解"世界如何运作"，只了解"人类选择用什么符号序列来描述世界"。

**触及不到的维度**：身体感受、空间直觉、因果干预的具身反馈——这些从未被人类语言编码过，因此从未进入训练数据。在 Token 序列上做任何建模，无论参数多大、数据多多，都还原不了被丢弃的维度。

## 两条逃逸路线

### ELF（Embedded Language Flows）— MIT 何恺明团队

把文字生成全过程留在连续向量空间，只在最后一步投影回人类可读文字。使用 Flow Matching 从噪声出发，沿学习到的速度场平滑演化到目标嵌入。32 个采样步生成质量超过离散模型 1024 步的结果。训练数据约 450 亿 Token，只有主流方法的十分之一。

### Cola DLM — 字节跳动 Seed 团队

先用 Text VAE 把语言压缩成更深层语义潜空间，再在纯语义空间用 Flow Matching 建模全局先验，最后解码回文字。论文明确说：扩散过程做的是"潜在先验运输"，不是"Token 级别的观测恢复"。20 亿参数，8 个基准，与同体量自回归模型和 1000 亿参数的 LLaDA 2.0 对比，连续路线的 Scaling 曲线健康。

**两篇论文的核心共识**：Token 不是语言建模的必要条件。连续空间可以做得更好、更快、更省。

## 如果 Token 范式衰退

1. **视频 Tokenizer 公司首当其冲**：VQ-VAE、MAGVIT、OmniTokenizer、Cosmos Tokenizer、VidTok——如果语言生成都迁移到连续空间，视频这类天然连续数据更没理由压成离散 Token
2. **"多模态"产品叙事失效**：当所有模态共享连续空间，"多模态能力"变默认配置，不再是差异化卖点
3. **Token 计费体系动摇**：扩散模型可能用固定步数生成任意长度文本，输出长度与计算量脱钩，Token 不再是成本的真实度量

## 开放问题

- "杀死 Tokenization" 不等于到达 AGI：ELF 和 Cola DLM 的训练数据仍来自人类产出——一个有损压缩后的世界
- LeCun 看到了这层，押注"能预测物理后果的世界模型"
- 新训练信号可能不在更多数据里，而在某种主动探索中——在世界中行动、承受后果、从反馈中学习（递归自我改进 RSI）
