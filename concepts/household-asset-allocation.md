# 家庭资产配置

## 核心原则

个人/家庭资产配置的核心不是"赚得最多"，而是**家庭现金流不断裂、关键目标能兑现、遇到冲击还能活下来**。先管现金流和风险，再谈资产配置和收益优化。

## 三层学习框架

### 第一层：稳住家庭盘子

1. **现金流管理**：月度现金流表、家庭资产负债表、年度收支预测。储蓄率、结余率、债务偿付率。
2. **应急储备**：覆盖 3-6 个月生活支出（收入越单一缓冲应越厚）。区分 T+0/T+1 流动性需求。
3. **债务管理**：优先处理高成本、低弹性负债。
4. **基础保险**：经济支柱优先保，保险是防止配置被意外中断，不是理财替代品。
5. **目标与期限规划**：短期钱、中期钱、长期钱分桶。期限错配是很多家庭配置失败的根源。

### 第二层：投资配置

1. **资产类别**：现金（流动性高但被通胀侵蚀）、固收（利率/信用/期限风险）、权益（长期增长强但波动大）、房地产（使用属性+杠杆+低流动性）、黄金/商品/另类（补充角色）。
2. **分散化与相关性**：持有很多基金≠分散，同涨同跌不算真分散。家庭自住房、职业收入、企业股权、股票基金可能高度同向。
3. **再平衡**：按时间间隔或偏离阈值周期调回原风险水平。新增资金优先补弱项，比卖出更温和。
4. **税后收益**：税前回报≠实际回报。不同账户/主体/持有期限的税负差异显著。

### 第三层：系统优化

1. **行为金融**：识别牛市加仓冲动、恐慌卖出、只看收益不看风险暴露等偏差。
2. **退休收入规划**
3. **传承安排**：怎么持有、怎么传递、突发事件谁能接手。
4. **极端情景压力测试**

## 风险承受能力三分离

- **风险承受能力**（财务上扛不扛得住）：单/双收入、房贷、抚养压力、职业周期相关性
- **风险承受意愿**（心理上受不受得了）
- **风险承担需求**（为实现目标需不需要承担这类风险）

## CFA 知识点优先级

对家庭配置最有用的 CFA 路径：
**Economics → Fixed Income → Portfolio Management → Level III Asset Allocation → Level III Portfolio Construction → Level III Private Wealth**

最直接有用的：Private Wealth Pathway（目标导向规划、家庭财务暴露管理、税收影响、传承）、Level III Asset Allocation（三种配置框架、风险预算、再平衡）、Level III Portfolio Construction（固定收益角色、负债驱动投资、现金流匹配）。

## 五问自检

不是"我会不会挑基金"，而是：
1. 家庭未来 12 个月现金会不会断？
2. 遇到失业/疾病/市场大跌，哪个环节先出问题？
3. 每一笔钱的用途、期限、风险级别是否匹配？
4. 组合回报来自哪些真实风险暴露？
5. 即使市场不配合，家庭目标还能不能大体实现？
