# 退出太难陷阱

## 核心命题

中国内卷的病灶不在「进入太容易」，而在「**退出太难**」。市场经济的破产是出清机制，是把 N（幸存者数量）降下来的那只手；而中国的**软预算约束**把这只手按住了。日本、台湾的 DRAM 厂是真破产、真消失，全球才出清到三家；中国的过剩产能被地方财政硬生生拖成了慢性病。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 制度发动机：财政分权 × 政治锦标赛

### 分税制（1994）：被迫创收的经营性主体
- 税收大头上收中央，支出责任（教育、医疗、基建、就业、维稳）大量留在地方
- 地方政府背着结构性财政缺口：事权远大于财权
- 行为逻辑彻底变——从公共服务者变为**必须自己创收的经营性主体**
- 要招商、要 GDP、要税基、要就业——这些直接决定能否填上窟窿

### 晋升锦标赛：零和排名赛
- 官员升迁高度挂钩于本地**相对**经济表现
- 「相对」意味着零和排名——邻省干得好，我的相对名次下降
- 本该合作的「全国一盘棋」变成**几十个诸侯之间的军备竞赛**
- 制造产能时根本不算「全国是不是已经过剩了」——那不是他的目标函数^[raw/agent/中国企业为何陷入内卷竞争.md]

## 补贴性进入：土地财政的交叉补贴

地方政府垄断土地一级市场，玩法是一套精巧的交叉补贴：
1. **工业用地**以极低价、零地价、甚至倒贴基础设施送出
2. 工厂带来就业 → 就业撑起**住宅和商业用地**的高价（这才是真正赚钱的地块）
3. 加上未来的税收和 GDP 政绩

「贴钱请你来建一个全国已经过剩的产能」对地方政府是**高度理性**的——它的会计科目和企业完全不同：它不要 ROIC，要的是土地升值、税基和政绩。

打包在一起（工业地价 + 税收返还 + 研发补贴 + 电价优惠 + 城投廉价信贷）=「招商引资」牌——**人为地把进入门槛压到真实经济门槛之下**。进入者多，不是因为市场真的还能容纳，而是因为有人在替进入者付入场费。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 为什么死不掉：软预算约束

### 科尔奈的经典概念
企业知道亏到一定程度有人兜底 → 不计后果地扩张和死扛。一个亏损的本地龙头：
- 对企业财务报表是该出清的负资产
- 对地方政府是就业、税基、社会稳定、政绩——「不能烂在我手里」
- 于是地方财政补贴 + 银行被窗口指导续贷 + 城投平台输血 → **僵尸产能**

### 行政区经济：每个省都要一条完整链
现代制造业有巨大的有效经济规模（MES）。全国最优结构是**少数几个超大工厂**。但财政分权给了每个省不可抗拒的激励——「我自己要有一个」。产能落在我的辖区才是我的；落在邻省，对我一文不值。

结果：几十套地理上分散、单个都达不到有效规模的重复产能。这是中国式过剩的指纹。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 市场分割：灌进入 + 堵出口的致命组合

地方政府两个方向相反的动作，指向同一个结果：
1. **灌进入**：对进来的投资极度欢迎（补贴战）
2. **堵出口**：对进来的外地产品极度设防（地方保护）+ 阻止本地企业退出

最强企业无法靠效率吃掉全国市场，因为每个省都保护自己那块。N 被锁死在高位。**这台机器，专门生产「1 元均衡」。**^[raw/agent/中国企业为何陷入内卷竞争.md]

## 两个「营商环境」的分裂

「营商环境」把两件方向相反的事缝在一起：
- **第一种（真正的好）**：审批快、不吃拿卡要、政策可预期、合同能执行、产权有保障——降低交易成本，本身不制造过剩
- **第二种（内卷发动机）**：官员下场当「店小二」「一把手招商」，给地、给钱、给税返、给信贷——营商环境越「好」，内卷越严重。地方比谁对企业更好，在宏观上是**逐底竞争**

更深一层：同一种「领导拍板就能给你地给你钱」的能力，今天把你招进来，明天在你该死的时候硬托着你不死。**让招商环境如此诱人的那个东西，正是阻止行业出清的那个东西。**^[raw/agent/中国企业为何陷入内卷竞争.md]

## 当前政策转向：人为压 N

顶层逐渐意识到 R&D 陷阱的危险，近两年出现组合拳：
- **全国统一大市场**：拆市场分割、拆地方保护
- **公平竞争审查**：清理招商引资中的违规财税补贴
- **反内卷**：人为推动出清

三件事指向同一个诊断——纯靠市场，中国这种结构出清不掉过剩玩家，必须从制度上改掉地方政府的目标函数和工具箱。^[raw/agent/中国企业为何陷入内卷竞争.md]
