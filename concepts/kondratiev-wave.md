# 康波周期：技术革命与长期经济波动

## 定义

**康波周期**（Kondratiev Wave），全称康德拉季耶夫周期，是经济学中一种为期50-60年的长期经济循环。由苏联经济学家尼古拉·康德拉季耶夫在1925年提出，核心发现是商品经济中存在比普通商业周期更长、波长达半个世纪的系统性波动。^[raw/agent/康波周期.md]

底层驱动力不是金融炒作或政策变动，而是**颠覆性技术创新**的集群式爆发。每次康波的兴起都伴随一次工业革命或核心技术的产业化落地——技术普及引发资本大规模开支（CapEx），拉动全球经济数十年繁荣；技术红利耗尽、产能过剩时，经济陷入长期萧条，直到下一次技术革命来临。

## 五次康波周期

| 周期 | 时间跨度 | 核心驱动技术 |
|------|---------|------------|
| 第一康波 | 1780s-1840s | 蒸汽机、纺织工业、早期冶金 |
| 第二康波 | 1840s-1890s | 铁路运输、钢铁工业革命 |
| 第三康波 | 1890s-1940s | 电气化、化学工业、内燃机 |
| 第四康波 | 1940s-1980s | 汽车普及、石油化工、合成材料 |
| 第五康波 | 1980s-至今 | 信息技术（IT）、互联网、智能手机 |

## 四个季节

一个完整康波划分为四个阶段（熊彼特命名）：

1. **春季：回升期** — 新技术开始从实验室走向大规模商业化，旧产能已被清洗。风险投资兴起，股票孕育新牛市，大宗商品处于低位。
2. **夏季：繁荣期** — 新技术全面普及成为基础设施。经济强劲增长，就业率高。后期伴随高通胀和大宗商品超级牛市。
3. **秋季：衰退期** — 技术红利边际递减，产能严重过剩。企业过度加杠杆，资产泡沫开始破裂（如2000年互联网泡沫、2008年次贷危机）。
4. **冬季：萧条期** — 经济进入通缩或滞胀，债务出清。**现金为王**，债券和黄金是安全避风港。全社会等待下一个颠覆性技术。

## 周金涛的涛动周期论

中国宏观分析师周金涛将康波理论发展为**"涛动周期论"**，核心观点：

### "人生发财靠康波"

个人财富积累主要源于经济周期提供的结构性机会，而非单纯个人努力。一生大致经历1次康波、3次地产周期（20年）、6次投资周期（10年，朱格拉周期）、18次库存周期（3-4年，基钦周期）。一生只有约3次重大财富机会，对应康波关键转折点，抓住一次即可实现阶层跃升。

### "宿命与反抗"

- **宿命**：出生时点基本决定你在康波中的位置（出生在回升期的人更容易成功，如巴菲特）
- **反抗**：通过研究周期规律、提前布局资产配置、宏观对冲来"顺势而为"

### 2026年定位

按周金涛框架，2026年处于**第五次康波（信息技术）萧条期的末尾，第六次康波（AI、新能源、生物科技）回升期的起点**。旧技术增量红利耗尽，新技术开始商业化加速。周金涛2016年预判：2025-2030年是普通人最后一次财富窗口，2026正是这个窗口的起点。

## 争议与局限

康波理论很有吸引力，但不能当"铁律"：

1. **周期长度不稳定**：有人说是40年、50年还是60年，难以精确验证
2. **历史容易事后解释**：经济学里容易出现"看起来像周期"的图形
3. **影响因素太多**：技术、战争、政策、利率、人口、全球贸易都会影响经济，很难说某次繁荣或衰退完全是"康波到了"
4. **学术地位**：Investopedia将其归入非主流/异端经济学范畴

## 实际用途（非预测工具）

康波理论最大的价值不是预测"哪一年发财"，而是提供观察长期产业更替的框架：

- **看技术**：哪些技术可能成为下一轮基础设施？
- **看产业**：哪些行业会从小众走向大规模应用？
- **看资本**：钱是不是正在集中流向某些新赛道？
- **看过剩**：某个热门行业是不是已经太拥挤？
- **看周期位置**：一个产业是在早期扩散，还是已经成熟甚至泡沫化？

## 与全天候策略的关系

雷·达利欧的全天候策略在宏观审视上与康波周期有"精神共鸣"（都敬畏长期大周期和债务出清），但在策略实施上有根本分歧：

- **康波运用逻辑**：主动择时——判断当前处于哪个季节，据此重仓某类资产
- **全天候逻辑**：放弃择时——构建在任何季节都能自动平衡的系统（将经济拆解为经济增长×通货膨胀四个象限，通过风险平价让每个象限风险贡献一致）

两者关系：康波理论是"气象历史图"（告诉你这几十年多雨、下几十年干旱），全天候策略是"全地形越野车"（不同时装备雨胎、雪地链和遮阳棚，无论外界如何都能平稳前行）。
