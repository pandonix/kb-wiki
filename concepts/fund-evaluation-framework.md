# 基金评价全景框架

## 核心原则

**真正的功夫不在于把每个数都算出来，而在于判断「对这只特定产品，哪条轴是绑定约束」。** 看多个指标并排，不是为了求精确，而是为了让任何单一指标都难以独自把你骗过去——最终你要理解的是产品的**收益生成机制**，指标只是逼近它的探针。^[raw/agent/夏普、IR、索提诺、卡玛比.md]

## 六维评价框架

### 一、风险调整收益（同一家族，换分母）

| 指标 | 分母 | 回答的问题 |
|------|------|-----------|
| **[[sharpe-ratio|夏普]]** | 总波动 | 每单位整体风险的绝对效率 |
| **索提诺** | 下行波动 | 每单位坏波动的效率；与夏普的缺口暴露偏度 |
| **[[information-ratio|IR]]** | 跟踪误差 | 剥离 β 后每单位主动偏离的选股/择时能力 |
| **[[calmar-ratio|卡玛]]** | 最大回撤 | 每单位最坏回撤的回报，关乎生存 |
| **Treynor** | β（系统性风险） | 只惩罚不可分散的那部分风险 |
| **Omega** | 整个收益分布 | 吃掉所有高阶矩的根本性升级 |
| **Pain/Martin** | Ulcer 指数 | 同时惩罚回撤深度和水下时长 |

### 二、α 的「打假」——归因与因子

IR 衡量相对基准的主动收益，但没回答：**这点超额是本事还是在偷偷承担风险？**

- **Jensen's α**：基于 CAPM，扣掉 β 应得的市场收益后的残差
- **多因子 α**（Carhart 四因子、Fama-French 五因子）：很多看似 α 的东西，拆开后只是规模、价值、动量等因子的 β 暴露。评估高 α 经理先问：这是真 α 还是因子 β 穿了马甲？
- **Brinson 归因**：拆成配置效应（选对板块）与选择效应（板块内选对券）
- **Active Share**：基于持仓衡量组合与基准差多少——抓出「高费率、低 Active Share」收 α 钱干 β 活的伪主动经理

### 三、不对称与市场状态

- **上行/下行捕获率**：牛市吃到基准涨幅的百分之几，熊市承担基准跌幅的百分之几。理想：上行 >100%、下行 <100%
- 比索提诺更直观的不对称度量，且区分了市场状态

### 四、尾部与路径

- **VaR/CVaR（期望损失）**：CVaR 是超过 VaR 之后的平均损失，真正刻画尾部厚度，补上夏普乃至索提诺抓不住的极端尾部
- **偏度/峰度**：负偏 + 高峰度 = 「卖尾部」型策略的指纹
- **水下时间/回本时间/Ulcder 指数**：补卡玛只看回撤深度、不管泡了多久的盲区

### 五、成本与结构（最被低估的一层）

前面全是数学，但实务里这些经常更决定最终到手的钱：

- **费率**（管理费 + 业绩报酬）：确定地、复利地侵蚀净收益。税前夏普漂亮的产品，费后可能平平
- **换手率**：暗示交易成本和税负
- **容量/规模（AUM）及趋势**：薄而广的策略有规模上限，膨胀会稀释 α
- **风格漂移**：基金是否还在执行声称的策略；一旦漂移，归因和组合搭配全部失效
- **经理任期与团队稳定性**：历史业绩是不是当前这套人马创造的

## 策略类型 × 绑定约束

| 策略类型 | 最关键的轴 | 原因 |
|---------|-----------|------|
| 权益主动基金 | 归因/因子 | 先把因子 β 剥干净，看残差 α |
| 卖波动/carry/信用 | 尾部与路径 | 夏普和卡玛在平静期会串通骗你 |
| FOF/组合配置 | Treynor、β、相关性 | 子基金在组合中的边际风险贡献 |
| CTA/趋势跟踪 | 卡玛/最大回撤 | 路径依赖是这类策略的核心风险维度 |
| 所有产品 | 成本与结构 | 费率、容量、风格漂移经常比数学更决定净结果 |

## 元前提

**所有这些指标都是对历史的、有估计误差的点估计。** 任何单一指标都能被某类策略精心打扮——看多个并排，是为了交叉验证。^[raw/agent/夏普、IR、索提诺、卡玛比.md]
