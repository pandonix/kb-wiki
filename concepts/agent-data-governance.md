# 企业Agent数据治理

## 核心洞察

企业 Agent 落地的真正瓶颈不是模型能力，而是**数据和知识体系能否被机器有效调用**。两位 CIO（顺丰集团刘潭仁、深信服宋东林）达成的核心共识：随着大模型能力趋同，模型和算力均可快速获取，但企业长期沉淀的数据、知识和业务理解，无法被轻易复制。^[raw/articles/2026-05-29-深度对话-后龙虾时代企业Agent从能用到生产级差距在哪里.md]

## 从"服务人"到"服务 Agent"的知识重构

顺丰集团正在构建的知识体系，本质上是**把原本面向人的知识，重组为机器可以调用的能力结构**。这要求：

- 全面梳理企业关键知识，识别哪些是真正的核心知识资产
- 重构数据结构，从散落在各类系统中的数据碎片，变成可被 Agent 检索和推理的结构化知识
- 搭建可自主迭代优化的数据系统，而非一次性知识库工程

现实中，大多数企业还没走到这一步：核心知识零散分布在各类系统中，业务经验沉淀在文档与员工个人认知里，高价值信息与无效历史数据边界模糊。^[raw/articles/2026-05-29-深度对话-后龙虾时代企业Agent从能用到生产级差距在哪里.md]

## Good Case / Bad Case 反馈闭环

Agent 进入业务流程后，AI 本身反过来参与数据治理：

- **Good case**：正确回答沉淀为优质数据，强化知识库
- **Bad case**：错误或不理想的回答暴露知识错误、数据冲突或口径不一致

这些反馈反向推动优化——AI 可以识别不同时间、不同来源之间相互矛盾的冲突数据，也可以清理知识库膨胀中产生的冗余信息。^[raw/articles/2026-05-29-深度对话-后龙虾时代企业Agent从能用到生产级差距在哪里.md]

数据治理正在从**单纯的人工维护，转向人机协同演进**。

## 与模型能力的对比

| 维度 | 模型能力 | 数据/知识治理 |
|------|----------|---------------|
| 获取难度 | 低（外采/开源） | 高（需长期积累+内部梳理） |
| 差异化价值 | 低（模型趋同） | 高（无法复制） |
| 持续投入 | 模型升级 | 数据和知识持续迭代 |
| 决定上限 | Agent 的"智商" | Agent 的"业务能力" |

## 生产级 Agent 的数据成熟度

顺丰 CIO 提出的四要素：**场景、数据、算法、算力**。其中：
- 算法：50% 可依托大模型解决
- 算力：多为外采
- **场景选择 + 数据知识治理**：核心障碍，需长期布局

"高频且痛"的场景 + 可被机器调用的知识结构 + 可衡量的业务结果 + 人工兜底与责任边界 = 生产级 Agent 的必要条件。^[raw/articles/2026-05-29-深度对话-后龙虾时代企业Agent从能用到生产级差距在哪里.md]
