# Token 经济

## 核心定义

Token 是 AI 处理和生成信息的基本单位——约等于 1-2 个汉字。Token 让 AI 能力变成了一种可以计量、定价和交易的东西，就像"千瓦时"让电力有价格、"桶"让石油有期货市场。

围绕这个单位，正在形成一套全新的经济逻辑：有价格、有供需、有产业链、有国际竞争、有待解决的制度难题。^[
Token经济学七问——一份关于AI新经济的入门地图.md
]

同样一个 Token，用来闲聊不值钱，用来写代码值 200 美元，用来法律文档审阅值 1000 美元。Token 的价值完全取决于它被"编程"做什么——这是传统生产要素（钢铁、石油、电力）完全不具备的属性。^[

## 计费单位已经扩散（2026年现状）

**单一 Token 计价的时代已经过去。** 主流厂商的实际计费体系：

| 维度 | OpenAI | Anthropic |
|------|--------|-----------|
| Token 推理 | ✅ 标准价 | ✅ 标准价 |
| Batch 处理 | ✅ 独立计价 | — |
| Priority/Fast | ✅ 独立计价 | ✅ Fast mode |
| Web Search | ✅ 独立计价 | — |
| Context Caching | ✅ Prompt caching | ✅ cache read 0.1x base |
| Session Runtime | ✅ Containers | ✅ $0.08/session-hour |
| 地域合规 | ✅ Regional pricing | ✅ data residency |

部分 SaaS 已开始按 outcome 收费（每"有效解决"收固定费用），不再按 Token 计。

## 关键悖论：单位成本下降 vs 单次任务总成本上升

OpenAI reasoning models 会生成内部 reasoning tokens（按 output tokens 计费）；Anthropic 开启 extended thinking 时 thinking tokens 依然完整计费。因此：
- 单位 Token 越来越便宜（5-10x/年）
- 但单次任务为获得更强思考能力消耗的 Token 总量上升
- **终端价格不降反升**

这不是悖论，只是**购买单位变了**：用户买的是任务完成率、等待时间、稳定性，不是 Token 数量。

| 层级 | 衡量指标 |

未来不是"token 经济消失"，而是 token 会下沉成底层清算单位。上层产品的定价会越来越像 **seat / tier / credits / outcome** 的混合体系。^[

## Token 不是货币，更像千瓦时

Token 具备货币的两项属性（计量单位、交换媒介），但缺失通用接受性、一般等价物和自由流通。它更像电力世界的千瓦时——不是货币，但衡量了电气化时代的生产力。^[
Token并不等同于"货币".md
]

按经济学教科书衡量货币的三大经典职能，Token 几乎在每一项上都力不从心：
- **价值尺度**：虽成为 AI 服务定价单位，但厂商间不等价、价格剧烈波动，无法提供稳定价值参照
- **流通手段**：实现了法币到 AI 服务的单向兑换，却不具备通用流通性，无法在 AI 之外的任何场景使用
- **储藏手段**：通缩趋势明显，持有预付 Token 只会持续贬值，完全不具备保值功能

一枚 OpenAI 的 Token 不能在 Anthropic 平台使用，与开源小模型的 Token 在成本和价值上也不等价。它更像游乐场代币——限定场景、不可互换、没有独立信用体系。^[
Token并不等同于"货币".md
]

但 Token 具备**清算单位属性**：它是 AI 服务交换的标准计量协议，标志着人类第一次能系统性地量化和交易"智能服务"。Token 的终局形态未必是"货币"，更可能是**智能经济的基础计量协议**。^[
Token并不等同于"货币".md
]

核心内在矛盾：Token 同时承担"成本度量"（算力物理消耗）和"价值度量"（智能输出效用），传统货币只承担后者。

Token 信用四弱点：脆弱性（公司可能倒闭）、分散性（各平台独立信用）、易变性（技术迭代快，信用窗口短）、数据安全信用（大规模泄露类似银行挤兑）。^[
Token并不等同于"货币".md

### Token 定价：从成本到价值的三重跃迁

## Token 定价：成本托底，能力拉开

Token 价格的形成机制是双重驱动：
- **底部**：GPU 瓶颈的成本传导托起（短期芯片主锚，中期电力约束，长期人才与知识密度）
- **顶部**：模型能力的价值溢价拉高（GPT-5 vs GPT-4 价格差数十倍，差异源自能力而非硬件）

定价锚迁移路径：GPU → 能源 → 人才方向。^[
Token并不等同于"货币".md
]

高端模型的溢价本质是训练成本的分摊 + 二级价格歧视（不同支付意愿用户自我选择分层）。

## Token 的产业周期

"短期紧缺 → 中期过剩 → 价格战 → 行业整合"路径：
- 低端 Token 市场：基础对话/简单任务，拼价格
- 高端 Token 市场：复杂推理/专业场景，拼效果和稳定性
- 开源模型（Llama、Mistral）建立低端价格天花板

## Token 需求的爆发路径

双 S 曲线叠加 → J 型爆发 → 次线性收敛：
1. 第一条 S 曲线（2023-2027）：人类用户驱动，受人类时间上限约束
2. 第二条 S 曲线（2025-2030）：Agent 驱动，24 小时运行 + 递归调用 + 长尾任务激活
- 杰文斯悖论：Token 越便宜越高效，反而用得越多
- 真正拐点：Token 成本降到人力十分之一以下 + 认知普及临界点
- 2026-2028 年可能是 J 型爆发的关键窗口

### 需求引爆的两个临界点

## Token 市场结构：分层式寡头垄断

2026 年的 Token 市场呈现**"分层式寡头垄断"**——两种市场状态在同一产业并存：^[Token生意在重新洗牌.md]

**高端层级（寡头结构）：** OpenAI、Anthropic、Google 构成稳固寡头。厂商间存在隐性价格协调——OpenAI 率先调价，其他跟进，呈现"寡头博弈"。但用户切换成本极低（只需改几行 API 代码），迫使寡头不敢过度定价。厂商正通过微调模型、专属功能和生态工具链构建"隐性锁定"。

**中低端层级（垄断竞争）：** 开源模型与众多云服务商提供差异化替代方案，构筑了闭源厂商的"价格天花板"——定价不能远离开源替代品水平。

两种力量的角力决定了市场走向：一边是"赢家通吃"飞轮（最强模型→最多用户→最多数据→更强模型），另一边是开源运动和垂直领域差异化瓦解集中化。合理猜测：市场可能稳定在 **"2-3 家通用寡头 + 开源中低端生态 + 众多垂直领域专精玩家"** 三层结构。**但警示：AI 行业技术变革极快，市场结构高度不稳定，一次重大技术突破就可能在瞬间颠覆现有格局。**^[Token生意在重新洗牌.md]

## Token 价格的全球分化

Token 价格的地区差异已非暂时现象，而是由**能源成本、芯片获取能力、产业政策**共同塑造的长期格局：^[Token生意在重新洗牌.md]

- **中国价格洼地**：中西部电力价格为加州 1/3~1/2，DeepSeek 等依托能源优势将推理成本压缩至美国同行几十分之一。出口管制倒逼出 MoE、量化压缩等"受限创新"，形成独特成本优势。地方政府竞相建设智算中心，以补贴电价吸引企业
- **跨境套利**：企业用国产模型处理非敏感任务，关键任务用 GPT；印度及东南亚也因成本优势成为算力部署新选择
- **三大限制**：数据合规（GDPR/中国数据出境）、延迟和品质差异、地缘政治断供风险
- **长期格局**：算力密集型产业向低成本地区流动，但受数据主权和地缘政治约束——类似制造业全球化与逆全球化的博弈

2026 年 2 月 OpenRouter 数据：平台调用量前五模型中有四款来自中国厂商（MiniMax M2.5、Kimi K2.5、GLM-5、DeepSeek V3.2）。a16z 合伙人 Martin Casado 估计，使用开源 AI 栈的初创公司中约 80% 跑在中国模型上。^[Token生意在重新洗牌.md]

| 公司 | 定价锚 | 战略意图 |

## 定价模式演化：三浪叠加

3-5 年内 Token 定价模式将经历 **"三浪叠加"**：^[Token生意在重新洗牌.md]

**第一浪：按量计费与包月订阅并行**（已发生）。API 按量计费，消费产品包月订阅（ChatGPT Plus）。

**第二浪：结果导向定价**（2-3 年内）。定价单位从"消耗了多少 Token"转向"完成了什么任务"。如"写一份合同 50 元"而非"消耗 10 万 Token 定价 X 元"。典型案例：Cursor 从固定订阅→请求配额→按模型使用量计费→Background Agents 任务执行。对用户来说，重要的是任务是否完成、代码能不能合并——用户真正愿意付费的对象正在从"模型调用"转向"任务完成"。

**第三浪：金融化和衍生品市场**（3-5 年内雏形）。当 Token 成为关键生产要素，企业需要对冲价格波动风险（类似航空公司对冲燃油价格）。Token 期货、算力互换合约等有明确市场需求。

三浪叠加的终局是**"混合定价体系"**：基础层按量计费（水电煤气）、应用层按结果/订阅（SaaS）、金融层有期货对冲（大宗商品市场）。

## 卖结果 vs 卖 Token 的双重困境

从"卖 Token"到"卖结果"的转变是大势所趋，但面临两个核心难题：^[Token生意在重新洗牌.md]

1. **"结果"的定义和衡量**：什么算"任务完成"？AI 写的代码有 bug 算不算？法律意见不够全面算不算？质量评估远比 Token 计量复杂
2. **风险承担转移**：按 Token 计费时，风险主要由用户承担；按结果计费时，风险转移到服务提供商——必须对模型能力、任务边界和交付质量有更强控制力

最可能的路径是**"Token 作为底层计费协议、结果作为上层商业包装"**，类似电信行业用户按"通话分钟"（底层）或"套餐"（上层）付费。

### 三层计价结构

Token 经济正在从底层用量计价走向结果层计价，形成三层结构：^[raw/articles/2026-06-08-Token经济进入结果层.md]

- **Token 层**：底层成本，类似电费、带宽、云资源
- **动作层**：业务步骤，例如更新记录、生成邮件、完成查询
- **结果层**：可验收完成件，例如解决客户问题、完成审核、处理工单

底层越标准，越容易被压成成本；上层越接近业务结果，越可能成为新的价格锚。

### 结果型 AI 案例：Intercom Fin

Intercom 的 AI 客服代理 Fin 是按结果定价的标杆案例：**每解决一个客户问题收费 $0.99，未解决则不收费。** 计价单位不是 seat、conversation、API call 或 token，而是 outcome。^[raw/articles/2026-06-08-Token经济进入结果层.md]

### 结果型 AI 的四个成立条件

结果型 AI 不是「按效果付费」的营销话术，而是一套交易结构。它至少需要：

1. **完成定义**：什么算做完（客服问题解决相对好定义；合同审核、财务对账等场景更复杂）
2. **归因证据**：怎么证明是 AI/服务方完成的（需要日志、流程记录、人工接管记录、质量统计和复盘机制）
3. **质量验收与计价**：同一用户追问、AI 处理一半后人工接手、一次对话解决多个问题、错误后补救等——都需要计价和对账规则
4. **责任分配**：只有愿意补救、重做、退款甚至赔偿，AI 软件才真正从工具变成「完成件」供应商

### 结果型 AI 让软件变重

按结果收费的 AI 不会让软件变轻，反而会让软件变重。它必须连接知识库、工单、身份、订单、审批流、模板库、版本记录、发票、支付流水、异常处理等系统——把人、流程、工具、规则和验收组织起来。^[raw/articles/2026-06-08-Token经济进入结果层.md]

### 场景适配性

并非所有场景适合结果收费。更适合的任务：高频、边界清楚、结果容易验收、失败可以补救、风险相对可控（客服、内容审核、对账、质检、规则检查）。越接近核心决策、核心客户和高责任风险（战略咨询、投行尽调、组织诊断），越不适合过早按结果外包。^[raw/articles/2026-06-08-Token经济进入结果层.md]

## Token 交易所的想象与现实

CoreWeave 2025 年纳斯达克上市，市值一度逼近 900 亿美元，高度依赖多年期 "take-or-pay" 合同（照付不议，石油天然气管道行业标准）。投资人开始像对待石油管道公司一样给算力基础设施定价——不看增长故事，只看长期合同和可预测现金流。^[Token生意在重新洗牌.md]

建立 Token 交易所需要两个前提：**Token 标准化**（不同模型 Token 品质差异巨大，需定义不同智能水平 Token 的可比性和互换比率）和**监管框架**。更可能先出现的是"算力现货交易平台"（类似电力现货市场），而非完整交易所。长期来看，交易所交易的标的物更可能是"标准化算力单位"（GPU 小时）而非 Token 本身。^[Token生意在重新洗牌.md]

## Token 定价与碳排放

AI 数据中心的碳排放是典型的**"负外部性"**：谷歌碳排放量五年上涨近五成，微软同年投入逾百亿美元购买清洁能源。理论上通过"碳税 + Token"模型内部化完全合理，但面临三重挑战：^[Token生意在重新洗牌.md]

1. 碳排放归因复杂（能源结构、冷却效率、GPU 利用率等变量）
2. 竞争中立性（各国碳税不同步导致"碳泄漏"）
3. 时机考量（过早抑制创新，过晚错过环保窗口）

更可行的近期路径：**自愿披露 + 绿色标签**（"绿色 Token"认证），中期引入碳排放配额交易，长期国际协调统一碳税标准。

## Token 市场不会走向 OPEC 式卡特尔

Token 市场不太可能出现 OPEC 式的卡特尔协调定价，三个原因：^[Token生意在重新洗牌.md]
1. 反垄断约束严格——AI 处于全球监管焦点
2. 开源"搅局者"无法被纳入——成千上万开源部署者是不可被协调的群体
3. 技术迭代速度太快——一次技术突破就能改变供给格局

更可能的走向是电信市场式的**"寡头价格竞争 + 非价格差异化"**。最终格局可能是"电信市场的竞争烈度 + 石油市场的品质分级 + 软件市场的版本策略"的混合体。

- 异质性：同一 Token 在不同场景创造价值差万倍
- 需区分"生产性消耗"和"消费性消耗"
- "Token 经济效率"（单位 Token 创造多少经济价值）是比总消耗量更有意义的指标
- 大量 Token 价值不经过交易，不被 GDP 统计——"暗物质"问题

### Token 效率：比总量更有意义的指标

"Token 经济效率"（单位 Token 创造的经济价值）是重要的经济诊断工具：^[
Token并不等同于"货币".md
]
- 持续上升 → AI 对经济的赋能在变得更高效
- 持续下降 → 可能是泡沫或浪费的信号

Token 消耗与经济产出的关系不是直线，而是 **S 型曲线**：早期企业学习试验，消耗增长快但产出跟不上；中期应用成熟，产出随消耗同步放大；后期边际收益递减，产出增速放缓。不同行业、不同国家处于曲线的不同位置，这也是"AI 对 GDP 的拉动"众说纷纭的原因。^[
Token并不等同于"货币".md
]

### 终局：从卖 Token 到卖结果

这场 Token 经济的叙事核心不是它会不会成为货币，而是效率、结构与控制权的再分配：^[
Token并不等同于"货币".md
]
- 谁能用更少的 Token 创造更多价值，谁就掌握新生产力
- 谁能构建更高效的 Agent 系统，谁就拥有新组织优势
- 谁能定义标准、掌控入口、形成生态，谁就获得"新基建"的数字基础设施地位

从卖 Token 到卖结果，就像从"卖电"到"卖光明"。Token 不是答案，而是一个信号：我们正在从"使用工具的时代"走向"构建自动化系统的时代"，从"劳动驱动的增长"走向"机器驱动的经济"。^[
Token并不等同于"货币".md
]

## Token 范式面临的架构挑战
