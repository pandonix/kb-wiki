# 内卷作为结构理性均衡

## 核心命题

**内卷不是非理性，而是特定结构条件下的理性均衡。** 真正该问的不是「企业为什么不聪明地去赚100元」，而是「什么结构条件决定了一个行业最终停在100元的寡头均衡，还是塌缩到1元的商品化均衡」。^[raw/agent/中国企业为何陷入内卷竞争.md]

四个条件同时缺席，导致中国企业系统性地无法形成护城河：
1. 站在技术前沿，且别人短期追不上
2. 规模报酬递增 / 网络效应 / 生态锁定
3. 资本密度高到只能容纳少数玩家（自然寡头）
4. 知识产权真的能挡住人

中国制造业的强项几乎全部集中在「护城河最浅」的价值链环节——这不是偶然，是历史进入路径决定的。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 关键变量 N：幸存者数量

一个行业能不能停在高价均衡，几乎完全由**幸存者数量 N** 决定：

- **N=3**：可以靠重复博弈、焦点、相互克制达成默契合谋（DRAM 三巨头几十年的模式）
- **N=50**：默契必然崩溃——只要有一个人降价抢份额，所有人的定价权立刻归零

卡特尔稳定性随 N 单调下降。中国的问题不出在「进入太容易」，而在「**退出太难**」——出清被地方政府招商竞赛、银行续贷、就业维稳持续打断。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 四个结构性条件在中国为何缺席

### 1. 技术前沿位置
中国大多数行业长期处于快速跟随者地位。护城河存在于前沿——你在创造别人还拿不到的新知识。追赶者复制已知前沿，超额利润窗口本就极窄。

### 2. 资本目标函数错误
便宜资本 + 增长 KPI + 地方官员晋升锦标赛 → 目标函数是「建成了多少」而非「赚回了多少 ROIC」。政策点名「战略行业」制造**保证过剩**。

### 3. 退出机制失效
地方政府从供给侧把 N 顶高（灌进入），不安全感从需求侧让每个玩家不敢做降低 N 的事（建护城河、忍耐、整合）。两头一夹，1 元均衡被锁死。

### 4. 市场分割（诸侯割据）
地方政府补贴进入 + 阻止退出 + 保护本地市场 = 最强的企业无法靠效率吃掉全国市场，N 被锁死在高位。

## 自我强化陷阱

```
低毛利 → 没钱投 R&D → 够不到前沿 → 只能继续在商品化层面卷 → 低毛利
```

而英伟达模式是反过来的飞轮：
```
高毛利 → 高 R&D → 拉开前沿 → 守住毛利
```

**「护城河-租金」模式真正的价值，不是赚钱本身，而是它生成了打下一场前沿战争的弹药。** 内卷模式饿死了 R&D，可能把企业永久锁在前沿之下。这是熊彼特意义上最该警惕的地方。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 这不是民族性——反例的存在

如果中国企业天生不会建壁垒，那 DJI、宁德时代、华为、海康、迈瑞就不该存在。它们的共同点恰好印证了结构分析：**凡是真正摸到并守住前沿、或所在行业本就高度集中的中国企业，护城河和高毛利就会出现。** 卷不卷，取决于行业是否满足上述四个条件，而非企业家的「格局」。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 消费者剩余与国家战略的双面性

摧毁国内利润的同一个机制，制造了巨大的消费者剩余和出口竞争力。光伏全球白菜价加速脱碳，电动车快速平价——从股东回报看是 bug，从国家战略看常常是 feature（哪怕是非意图的副产品）。^[raw/agent/中国企业为何陷入内卷竞争.md]
