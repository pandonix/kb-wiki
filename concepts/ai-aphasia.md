# AI 失语与错误谱系

## 核心定义

AI 失语（AI Aphasia）是一种不同于幻觉和谄媚的模型故障：**模型知道答案、能旁敲侧击描述答案、可以从多个角度证明它知道，但就是无法直接输出目标词。** 语义通路完整，表层生成通路断裂。^[raw/articles/2026-05-29-AI为什么会失语.md]

## 机制：训练不足词元 + 灾难性遗忘

### 训练不足词元（Under-trained tokens）

研究者在 GPT-2、Llama、Mistral 等主流开源模型词表中发现大量"没真正学会"的 token。每个模型词表里都有数千个这样的 token。这是因为分词器（Tokenizer）基于 BPE 算法按语料频率切分字符，低频组合被拆散，独立 token 在后训练阶段缺少练习机会。^[raw/articles/2026-05-29-AI为什么会失语.md]

### 灾难性遗忘（Catastrophic Forgetting）

大模型训练分两阶段：预训练（万亿 token）和后训练（百万到千万 token）。预训练阶段见过某 token，但后训练阶段该 token 出现不足 5 条，其向量被高频 token（工具调用标记、代码符号、安全拒答模板）持续挤压，推离了原本正确的生成概率区域。邻近 token（发音/字形相似的）被错误激活，产生替代输出。^[raw/articles/2026-05-29-AI为什么会失语.md]

### 对齐税（Alignment Tax）

对齐税指模型在对齐过程中损失的一部分预训练能力：准确性、知识广度、生成多样性都有不同程度折损。失语是对齐税的一种具体表现——模型学会了"怎么说话"（对齐），但忘了"说什么"（知识召回）。^[raw/articles/2026-05-29-AI为什么会失语.md]

## 舌尖现象类比

借用 1966 年 Brown 和 McNeill 的"舌尖现象"（Tip-of-the-tongue, TOT）范式以及 1991 年的传输不足假说（Transmission Deficit Hypothesis），AI 失语与人类"话到嘴边说不出"机制同构：

- 失语 ≠ 失忆：模型内部表示里有该知识，但走不到输出端
- 连接强度衰减：如同老年人脑中不常用的词，低频 token 在后训练中被高频 token 挤压
- 替代输出是诊断信号：模型蹦出的近似词（"嘉轩"、"佳琪"对"嘉祺"）来自相邻向量空间的错误激活

工程含义：基于"输出对错"的评测方法，会漏掉这类故障。需要专门的探针式评测，检查内部激活和表征完整性。观察错误输出形态比统计对错率更能定位故障层级。^[raw/articles/2026-05-29-AI为什么会失语.md]

## AI 错误谱系

失语不是孤立现象，而是 AI 错误地图上的一个新位置。这张地图目前包括：

| 错误类型 | 根因环节 | 发现方式 |
|----------|----------|----------|
| 幻觉（Hallucination） | 预训练知识与生成机制偏差 | 标准评测 |
| 谄媚（Sycophancy） | RLHF 偏好建模 | 专门测试集 |
| 过度拒答（Overrefusal） | 安全对齐过度 | XSTest 专用集 |
| 反转诅咒（Reversal Curse） | 自回归训练方向性 | 社区发现（GPT-4） |
| Lost in the Middle | 长上下文位置偏差 | Needle-in-a-Haystack |
| 失语（Aphasia/Under-trained tokens） | 后训练稀疏暴露 | 高密度用户提问暴露 |

**共同特征：**
1. 单一准确率指标无法捕捉任何一种
2. 每种错误对应训练流程的某个具体环节
3. 同族错误有亲缘关系（失语和反转诅咒同属"知识在但调不出"，机制不同但症状相邻）
4. 大多先被用户和社区发现，再被研究者定位和命名^[raw/articles/2026-05-29-AI为什么会失语.md]

## 分词器偏差

分词器的不均匀颗粒度造成了系统性偏差：

- 同一段中文文本和缅甸语文本的 token 数量差异最高可达 15 倍
- 影响：费用差异（按 token 计费）、上下文长度、理解质量
- 资源稀少语言在每一层都吃亏，与失语共享底层结构：**分词器决定一切的起点**^[raw/articles/2026-05-29-AI为什么会失语.md]

## 修复方向

MiniMax 的修复路径：在后训练阶段，给词表里每一个 token 都安排上最低限度的训练机会，保护低频 token 的连接强度不被高频 token 持续挤压。^[raw/articles/2026-05-29-AI为什么会失语.md]

更深层的启示：**AI 系统的健康正在被使用强度悄悄定义。** 高频高强度应用的领域故障会被快速看见，低频或边缘群体使用的领域故障正在沉默地累积。
