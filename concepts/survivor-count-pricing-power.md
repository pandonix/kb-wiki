# 幸存者数量 N 与定价权

## 核心命题

**一个行业能不能停在高价均衡，几乎完全由幸存者数量 N 决定。** 卡特尔的稳定性随 N 单调下降——这是理解中国式内卷与韩国式寡头差异的最关键变量。^[raw/agent/中国企业为何陷入内卷竞争.md]

## N=3：寡头默契均衡

当行业只剩 3 家时：
- 可以靠**重复博弈**维持克制——今天降价抢份额，明天对手会报复
- 形成**焦点价格**——心照不宣的价格锚点
- **相互克制**成为理性选择——每家都清楚，发动价格战的长期代价远超短期收益

DRAM 三巨头（三星、SK 海力士、美光）几十年就是这么过来的。这不是显性合谋（那违法），而是**默契合谋**（tacit collusion）——重复博弈下的自发克制。^[raw/agent/中国企业为何陷入内卷竞争.md]

## N=50：商品化均衡

当行业有 50 家玩家时：
- 默契必然崩溃——总有一家肯降价抢份额
- 所有玩家的定价权立刻归零
- 价格逼近边际成本（伯特兰竞争的结果）
- 行业利润从 100 元塌缩到接近 1 元

这就是**租金耗散**：只要一块利润容易被争夺，企业就会不断投入资源（扩产、补贴、降价），直到争夺成本几乎等于这块利润。^[raw/agent/中国企业为何陷入内卷竞争.md]

## 博弈论基础

### 伯特兰竞争
同质产品、价格透明、低转换成本 → 价格逼近边际成本。中国制造业尤其容易接近这种模型。

### 囚徒困境
| | B 不降价 | B 降价 |
|---|---|---|
| **A 不降价** | 10, 10 | 0, 15 |
| **A 降价** | 15, 0 | 1, 1 |

无论对手怎么做，降价都是占优策略。**个体理性，集体非理性。**^[raw/agent/中国企业为何陷入内卷竞争.md]

### 租金耗散的竞赛模型
N 家企业竞争 100 元利润，每家投入 e_i。对称纳什均衡下，10 家企业各投入约 9 元，最终净利润仅 1 元。90 元被消耗在竞争本身中。

### 消耗战
亏损企业不退出，赌对手先倒下。「再撑一年，也许对手先撑不住。」地方补贴、银行续贷延长消耗战。

## 中国式 N 被锁死在高位的制度机制

### 补贴性进入（灌进入）
地方政府招商竞赛 → 工业用地零地价/倒贴 → 每个省都要有自己的整车厂/晶圆厂/光伏基地 → 新进入者源源不断

### 退出太难（堵出口）
- **软预算约束**（科尔奈）：企业知道亏到一定程度有人兜底
- 地方财政补贴 + 银行窗口指导续贷 + 城投平台输血
- 亏损产能被托成**僵尸产能**

### 市场分割（诸侯割据）
地方保护主义 → 最强企业无法靠效率吃掉全国市场 → 没有人能长成主导定价的寡头

两台引擎叠加：地方政府对**进来的投资**极度欢迎（补贴战），对**进来的外地产品**和**本地的退出**又极度设防（保护主义）。一个灌进入，一个堵出口，指向同一个结果——**把 N 顶在高位**。^[raw/agent/中国企业为何陷入内卷竞争.md]

## N 与市场大小的悖论

中国的「大」在这里是诅咒：市场大到足以支撑 50 个亚规模玩家，于是就真的存在 50 个，谁都达不到有效规模和定价权。

韩国的「小」反而是福气：国内市场养不活几家，逼着它早早出清、早早出海、早早在前沿正面竞争。

注意同一文化谱系（儒家/科举）的韩国走向了极度集中（寡头、护城河、高毛利），而中国走向了极度分散。**一个变量在两个共享同样文化的国家里取了相反的值，那么文化就不可能是区分变量。** 区分变量是结构——市场大小、财阀政策、强制出清、出口导向。^[raw/agent/中国企业为何陷入内卷竞争.md]
