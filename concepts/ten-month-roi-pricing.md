# API 十个月回本定价模型

## 核心定义

DeepSeek 的 API 定价逻辑：**买一批设备回来，十个月收回成本即为合理利润。** 这不是利润最大化，而是"合理利润"原则——在当前市场条件下，这约等于年化约 120% 的硬件投资回报率，但梁文锋承认"还有降价空间"。^[raw/articles/2026-07-23-梁文锋投资者交流会-DeepSeek以AGI愿景驱动开源与克制.md]

## 定价公式

```
合理价格 = 硬件成本 / 十个月预期 token 消耗量
```

其中硬件按三年或五年做财务摊销，但商业上以十个月回本为标准。这个定价既不是边际成本定价（太低），也不是需求弹性最大化（太高），而是一个**基于资产周转率的主观锚点**。

## 与利润最大化定价的对比

梁文锋明确指出：在当前价格区间，用户需求是没有弹性的——**价格翻一倍，token 消耗量区别不大，总收入接近翻倍。** 但 DeepSeek 选择不这样做，因为愿景是"让这个东西对人有用，而不是赚最多的钱"。^[raw/articles/2026-07-23-梁文锋投资者交流会-DeepSeek以AGI愿景驱动开源与克制.md]

| 定价策略 | 逻辑 | DeepSeek 的选择 |
|---------|------|---------------|
| 利润最大化 | 利用价格非弹性，设高价 | ❌ 否决 |
| 边际成本定价 | 价格 = 边际推理成本 | ❌ 太低，无利润 |
| 十个月回本 | 硬件投资 10 个月回收 | ✅ 执行中 |
| 进一步降价 | 模型优化后成本更低 | 🔮 梁文锋说"还有空间" |

## 竞争含义

1. **成本壁垒**：DeepSeek 能以十个月回本定价，但"其他家做不到，成本要比这个高好几倍"——这个差距来自工程优化而非硬件成本
2. **价格战被动优势**：如果行业打价格战，DeepSeek 的利润空间比对手大几倍
3. **商业模式防火墙**：对手无法通过降价把 DeepSeek 挤出市场，因为它的定价已经接近自己的成本下限

## DCCP 降价故事：内部反馈信号

DeepSeek 的 DCCP 模型初期因担心需求太多定价较高，"团队里大家不是很高兴"。降价到四分之一后，"公司群里面很多人是欢呼的"。梁文锋认为这个反应揭示的是"真实想法"——**公司的动力系统不是利润，而是让技术变得便宜、好用、人人能用。**^[raw/articles/2026-07-23-梁文锋投资者交流会-DeepSeek以AGI愿景驱动开源与克制.md]

## 与竞对的差异

> "降价这样对于我们其他的竞争对手来讲，肯定不是个好事，他们一定不是欢呼的。因为你的收入、你的 ARR，你降一半，ARR 就掉一半。"^[raw/articles/2026-07-23-梁文锋投资者交流会-DeepSeek以AGI愿景驱动开源与克制.md]

这个对比揭示：当一家公司的组织激励与商业定价的目标函数不一致时，价格战对它而言不是痛苦而是释放——这是**组织设计转化为竞争壁垒**的经典案例。
