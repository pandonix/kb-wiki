# 三种职业限制脚本的 Wiki 交叉分析

基于一段关于三种职业心理脚本的表述，跨 10+ wiki 页面进行交叉综合。

## 原文表述

三种限制职业发展的「剧本」：

1. **续集剧本（Sequel Script）**：今天的决策完全被过去的决策绑架。因为大学学了某个专业就认为只能投对口工作；死抱同一个框架，仅仅因为那是舒适区。
2. **讨好者剧本（Crowd Pleaser Script）**：在工作场合表达真实想法令人恐惧，特别是周围坐着一圈技术大牛时。于是随波逐流，因为「大家都这么说」就跟着做。
3. **史诗剧本（Epic Script）**：社会赞颂宏大叙事，洗脑你必须去改变世界，必须肩负神圣使命。在科技行业潜伏最深。

## 三种脚本的 Wiki 映射

### 1. Sequel Script ↔ 路径依赖 + 舒适区

**核心驱动：** 旧自我感受到生存威胁时自动触发抵抗。

- [[second-order-thinking]]：「一阶思维 ≈ 线性思维 + 路径依赖。大脑追求低能耗，选择『以前怎么做的，现在就怎么做』。一种局部最优解的陷阱。」
- [[ai-cognitive-debt]]：舒适区 = 认知债务。「用短期安逸透支长期成长。就像刷信用卡——债总是要还的。」
- [[psychological-survival]]：不是懒，是心理生存机制。「改变意味着旧身份可能『死亡』，生存机制自动触发抵抗。」
- [[three-poisons]]：安逸贪 — 「死守看似稳定的舒适区，不敢面对变动，同时又为自己的停滞内耗。」
- [[pareto-inefficiency]]：组织层面的路径依赖 — 「新人进来看到所有人都在演，只能快速融入。」

### 2. Crowd Pleaser Script ↔ 从众 + 讨好作为生存策略

**核心驱动：** 概念自我受到威胁，表达异议是高成本信号。

- [[psychological-survival]]：心理/概念生存 — 本能地守护非物质层面的自我身份。
- 弗洛伊德视角（raw 人生的觉醒之路）：讨好是童年时期的「生存策略」——只有在「乖」「听话」时才获得认可，大脑形成「只有讨好别人，我才是安全的」逻辑。
- [[life-awakening]] 阿德勒部分：「『不改变』是看似被动、实则主动的选择。改变需要承担风险，维持现状虽痛苦但安全。」
- [[pareto-inefficiency]] 共谋均衡：「谁先戳破『新衣』，谁就等于公开质疑上级权威——极高政治风险。继续演戏成本极低。」
- [[three-poisons]]：跟风式痴 — 「永远活在别人的标准里。」

### 3. Epic Script ↔ 宏大叙事 + 异化

**核心驱动：** 社会灌输的「意义」从内在动力异化为外部压迫。

- [[capitalist-realism]]：「想象世界的终结，比想象资本主义的终结更容易。」主导叙事殖民了想象力——你甚至无法想象不追求「改变世界」的人生。
- [[marx-alienation]]：异化 = 人创造的东西反过来支配人。社会灌输的「改变世界」使命，从内在追求异化为外部压迫。不是你拥有使命，是使命拥有你。
- [[human-meaning-agi]]：关键区分——设定目的 vs 实现目的。效率回答「怎么做最好」，回答不了「为什么值得做」。史诗剧本把「设定目的」的主动权从你手中夺走。
- [[confucius-life-stages]]：知天命 = 世界的规律 + 自己的天赋与边界 + 人生的责任与使命。从内在觉察生长出来的使命 vs 外部灌输的「你必须伟大」。
- [[three-poisons]]：成功认知痴 — 「把单一成功标准当真理。『改变世界』本身可以变成另一种单一标准。」

## 共享底层机制

三种剧本表面不同，核心相同：**都是心理生存策略，且都把主体性交给了外部。**

| 剧本 | 交出主体性的对象 | 核心wiki概念 |
|------|-----------------|------------|
| 续集剧本 | 过去（路径依赖） | [[psychological-survival]] + [[second-order-thinking]] |
| 讨好者剧本 | 他人（群体评价） | [[psychological-survival]] + [[pareto-inefficiency]] |
| 史诗剧本 | 社会（外部意义） | [[capitalist-realism]] + [[marx-alienation]] |

[[psychological-survival]]：「你的心智是一套生存策略的集合，这正是改变如此艰难的根本原因。」

## 打破路径

[[life-awakening]] 三阶段对应三种剧本的破解：

1. **弗洛伊德（理解过去）** → 识别 Sequel Script 的路径依赖本质
2. **阿德勒（承担当下）** → 打破 Crowd Pleaser，收回被交出去的表达权
3. **荣格（觉察内在）** → 识破 Epic Script 中被植入的外部叙事

[[confucius-life-stages]] 平行路径：不惑（建立自己的价值判断）→ 知天命（找到自己真正该承担的事）→ 耳顺（不在意他人评价）。
