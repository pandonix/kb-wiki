# 哈耶克（Friedrich Hayek）

## 概述

弗里德里希·哈耶克（1899-1992），奥地利裔英国经济学家、哲学家，1974 年诺贝尔经济学奖得主。以对计划经济批判、知识问题（knowledge problem）和自发秩序（spontaneous order）的论述闻名。

## 知识分散诅咒（The Knowledge Problem）

1945 年，哈耶克在经典论文《知识在社会中的运用》（The Use of Knowledge in Society）中提出：

> **分散在个体手中的私有知识，永远无法被一个中央权威完整收集。**

这一洞见在 80 年后直接击中了多 Agent AI 系统的核心困境：Orchestrator（中央编排者）试图在一个永远存在信息差的盲区里，代替所有人做全局最优决策。^[raw/articles/AI 不会合作？那是因为他们没见过市场经济｜Hao好聊趋势.md]

## 与 AI 多 Agent 系统的映射

| 哈耶克的框架 | AI 多 Agent 映射 |
|-------------|-----------------|
| 计划经济（中央计划者） | Orchestrator-Worker 模式 |
| 知识分散诅咒 | Orchestrator 无法掌握每个 Agent 的真实能力和信心 |
| 价格信号 / 无形之手 | Economy of Minds 的拍卖 + 桶旅式支付 |
| 自发秩序 | 无编排的市场机制下合作自然涌现 |
| 市场发现过程 | 专才通过竞争暴露「谁最适合干这件事」 |

## Economy of Minds 的哈耶克证明

哈佛/MIT 的 Economy of Minds 论文用实验直接验证了哈耶克：**市场机制在足够时间后收敛到的均衡态 ≈ 全知全能中央规划者能达到的最优配置。** 换句话说，计划经济的理论上限，市场经济能在实践中达到。
