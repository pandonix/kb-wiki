# 张小龙（Zhang Xiaolong）

## 概述

张小龙是微信的创始人，被誉为"微信之父"。他的产品哲学以**去中心化、用完即走、工具应该隐形**为核心，深刻塑造了微信从社交工具到超级 App 的演化路径。

## 核心产品哲学

### 去中心化

张小龙在小程序设计上最坚持、也最反常识的决定是拒绝中心化分发：不给小程序做应用商店、不做排行榜、不做中心化分发入口。发现机制刻意设计为去中心化——扫码、社交分享、搜索，都是场景触发。这背后的价值取向是：**平台不应替用户决定该看到什么、用什么**。^[raw/agent/微信AI Agent.md]

### 用完即走

小程序的核心设计口号是"用完即走"，目标是去掉 App 的安装/卸载摩擦，让低频长尾服务即用即走。这反映张小龙的产品理想：**工具好到让你感觉不到它的存在**，而非用各种手段留住用户。

### 移动互联网的根本矛盾

张小龙认为移动互联网的核心矛盾是：**用户注意力极度稀缺 + 设备资源有限 + 服务获取摩擦巨大**。小程序本质上是在微信已建立的连接与信任网络之上，构建一个更低摩擦的服务分发与执行层。^[raw/agent/微信AI Agent.md]

## 与微信 AI Agent 的张力

微信 AI Agent 项目直接向张小龙汇报，这在腾讯内部是极高规格的重视信号。但该项目与张小龙的去中心化哲学存在根本性张力：

- Agent 必须通过调度选择服务（"帮我点杯附近的咖啡"），选择权和排序权重新回到平台手中——这正是张小龙当年最想避开的中心化分发。^[raw/agent/微信AI Agent.md]
- 小程序原本是商家的产品触点和品牌界面，在 Agent 模式下被降维成 Agent 调用的服务接口（类似 MCP-server），品牌和体验被抽掉。^[raw/agent/微信AI Agent.md]
- 项目汇报线本身就是一个信号：这不仅是产品决策，更是一场关于"走哪条路"的价值观裁决——**张小龙是否愿意为了 Agent 的可行性，部分妥协自己坚持的去中心化理想**。^[raw/agent/微信AI Agent.md]

## 第三条路的可能性

分析指出，全市场只有微信有条件走"既要 Agent、又不背叛去中心化"的道路——平台角色从排序推荐者退回到市场基础设施提供者（管协议、管信任、管支付、管仲裁，但不管选谁），盈利位置从"排序抽成"换成"结算抽成"。微信已经握着支付和金融，不需要靠垄断推荐位变现。^[raw/agent/微信AI Agent.md]
