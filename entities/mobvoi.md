# 出门问问（Mobvoi）

## 概述

中国 AI 公司，由 [[li-zhifei]] 于 2012 年创立。使命是「定义下一代人机交互」。业务经历过语音助手、智能手表、AI 配音等阶段，获 Google 和大众合计超 2 亿美金投资。2025-2026 年在李志飞驱动下进行激进的全栈组织转型，自研 [[codebanana]] 作为组织操作系统。^[raw/articles/如何把超级个体的产能，转化成组织能力？ AI跃迁者调研_腾讯新闻.md]

## 组织转型

### 转型特征
- 「自杀式转型」：旧世界既往不恋，组织形态完全面向未来
- 创始人独裁驱动，CEO 亲自下场写代码
- 从 300 人压缩到约 150 人

### 关键时间线
| 时间 | 事件 |
|------|------|
| 2025.06 | 李志飞三天写出近 20 万行代码，做出「AI 版飞书」原型 |
| 2025.08 | 发布产研全栈转型铁律：不分工种、不允许手写代码 |
| 2025.09 | 每人重新面试，半小时做以前一周的活 |
| 2025.12 | 产研团队全部全栈化 |
| 2026 | 推非产研成为[[system-designer]] |

### 转型成果
- 工程师约为去年一半，工作量约两倍，组织效率约 4-5 倍
- Token 成本一度达人力成本 15%，人均约 2000 美金/月
- 主动离开加优化约 20%-30%

## AI 原生组织特征

- **全栈化**：不分前端后端测试工种，产品经理也能指挥 Coding Agent 完成前后端部署上线
- **系统设计师**：非产研中约 30-40% 能端到端指挥 Agent 上线系统（销售自己写 CRM，HR 上线招聘网站）
- **Agent 作为正式员工**：有 A2A 通讯、Skill 商店、Teams.md 通讯录、Dashboard 量化指标
- **所有人运行在 CodeBanana 上**：没有例外

## 业务结构

维持老项目（数字人、配音、智能硬件）的同时新做 TicNote 和 CodeBanana，复杂度非常高。

## 未解挑战

- 商业验证：降本做到但营收不一定立刻变好
- 超级个体撕裂组织的痛苦没过去
- 转型路径激进，不一定适用于大组织
- 从超级个体工具到组织工具的产品定位之争
