# 橘子（冯雷）— ColaOS / ListenHub 创始人

## 概述

橘子（本名冯雷），ColaOS 和 ListenHub 创始人，AI 自媒体 AGENT橘 主理人。前 MiniMax 产品负责人、BOSS 直聘产品经理。他是 AI-native 组织实践的代表人物，其团队以「Agent 在组织人」的理念闻名。^[2026-06-01-一个理想的组织是AI Agent在组织人.md]

## 关键产品

- **ColaOS**：面向 2030 年的 Agent 操作系统，通过语音交互提供生成图片、音乐、视频、操控电脑/浏览器等能力，内置灵魂系统（思绪、觉知、心迹、牵挂）
- **ListenHub**：AI 音频与内容创作工具，后被改造为 [[one-person-company|一人公司]] 模式，由单开发者 + Agents 维护 20 个 repo，产出提升 10 倍以上
- **AGENT橘**：AI 自媒体，发布了包括《互联网已死，Agent永生》在内的有影响力的文章

## 组织实践

橘子在 ColaOS 团队（约 20 人）中实践了以下组织创新：
- 设立 [[soul-team|Soul Team]] 维护叙事一致性
- Builder + Explorer 二分架构
- 一天一版发布节奏
- 管理层（CEO/CTO/COO）+ 所有人平级推进
- Token 自由但配 ROI 约束
