# 微软（Microsoft）

## 概述

微软是全球最大的科技公司之一，在 AI 时代通过战略投资和产品整合成为核心玩家。CEO [[satya-nadella|萨提亚·纳德拉]]自 2014 年掌舵后推动公司从 Windows 中心向云和 AI 转型，主导了与 OpenAI 的深度合作。微软的 Azure 云平台是 AI 训练和推理的核心基础设施之一。

## AI 战略

### OpenAI 投资与合作

微软是 OpenAI 的最大投资者和独家云合作伙伴，累计投资超 130 亿美元。合作关系包括：
- Azure 作为 OpenAI 的独家云服务提供商
- 微软持有 OpenAI 约 27% 股份（价值约 1350 亿美元）
- 收入分成协议持续至 AGI 实现或合同期满

### Token 资本与 Frontier Firm

2026 年，纳德拉通过 [[token-capital|Token 资本]]概念阐述了微软对 AI 时代企业未来的愿景：企业不应只是模型消费者，而应构建自己的 AI 学习系统。微软提出 **Frontier Firm** 组织构想：三阶段演进（Human with assistant → Human-agent teams → Human-led, agent-operated），传统 org chart 变为围绕目标临时组织的 dynamic Work Chart。^[raw/articles/2026-06-15-微软CEO长文提出新概念token资本-AI时代企业生死的关键.md]

### 微软的 AI 实践

- **内部**：确保每位员工以最不受限制的方式使用 Microsoft 365 和 GitHub Copilot
- **GitHub Copilot**：从月费订阅转向按 token 计费——连续三年补贴用户，证明 AI 经济的补贴不可持续
- **Azure Foundry**：完整 AI 应用服务器，结合无状态 API + 计算 + 存储 + 数据库
- **数据中心建设**：面临电力而非芯片的瓶颈——最大问题是在靠近电源处足够快地完成数据中心建设

## AI 组织实践

在 [[ai-native-organization]] 框架中，微软的探索包括：
- **Builder 角色**：纳德拉定义的跨职能角色，超越传统「工程师」边界
- **Work Chart 替代 Org Chart**：动态组织围绕目标临时聚合
- **人机协作三阶段**：辅助 → 团队 → 运营

## 关键数据

- 2026 年 Azure 合同义务（RPO）超 4000 亿美元，平均履约周期 2 年
- 全球 400+ 光纤运营商合作铺设数据中心网络
- 在威斯康星州建设 2GW 数据中心
