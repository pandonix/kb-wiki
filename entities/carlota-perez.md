# Carlota Perez

## 概述

委内瑞拉裔英国经济学家，以技术革命与金融资本的周期理论研究闻名。代表作《技术革命与金融资本》（Technological Revolutions and Financial Capital, 2002）将熊彼特创新理论、明斯基金融假说与康波周期整合为统一框架，系统解释了过去两百年来五次技术革命的共同轨迹。

## 核心理论

- **技术-经济范式**：每一次重大技术集群（蒸汽机、铁路、电力、石油、ICT）都会经历约 20-30 年的波动周期
- **金融资本双重角色**：既是新技术扩散的点火器，也是泡沫放大的放大器
- **五阶段周期**：技术突破 → 金融资本狂热 → 泡沫破裂 → 制度重构 → 新一轮"黄金时代"
- **Installation Period vs Deployment Period**：技术革命的安装期（资本主导）与部署期（生产主导）之分

## 对当代的判断

- 当下 ICT 范式的 Installation Period 被异常拉长，黄金时代本应在 2010 年代到来
- AI 可能是 ICT 范式内部的子浪潮，也可能在孕育第六次技术革命
- 金融资本的"试错"不是中性的：会制造自我实现的压力，有强烈的相关性偏好
- 真正的范式判定需要"实体经济渗透率"作为检验，而非市值或投融资规模

## 与 Minsky 的根本分歧

- Perez 认为金融资本具有筛选功能，泡沫是必经阶段
- Minsky 认为金融资本没有筛选功能，只有自我强化的不稳定倾向
- 当代综合视角（Mazzucato, Gabor）：技术-金融耦合确实存在，但金融资本不会自动从 Installation 切换到 Deployment
