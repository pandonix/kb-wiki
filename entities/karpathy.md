# Andrej Karpathy

## 概述

前 Tesla AI 总监、OpenAI 联合创始人之一，当前独立从事 AI 教育和工具开发。以"Vibe Coding"概念推动 AI 编程讨论，提出 Agentic Engineering 是下一个关键方向。

## 核心观点（2026年访谈）

### Vibe Coding 只是开始

- Vibe Coding = 自然语言描述意图，AI 生成代码，人只做高层方向控制
- 当前状态：适合小项目和个人项目，大项目仍需工程纪律
- 风险：代码不可读、不可维护、debug 困难

### 真正重要的是 Agentic Engineering

- 从"人写代码"到"人设计系统、Agent 执行"的转变
- 关键技能变化：从编码能力到架构设计、意图精确表达、反馈闭环设计
- 类比：从"写汇编"到"写高级语言"——抽象层次提升

### 对 AI 编程三阶段的判断

- 第一阶段：AI 辅助补全（Copilot 时代）
- 第二阶段：Agent 自主执行（Vibe Coding / Claude Code 时代）
- 第三阶段：AI 作为全栈工程师（端到端系统构建）
